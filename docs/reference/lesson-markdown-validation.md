# 课例 Markdown 候选校验

原生任务在提交四阶段正文候选前运行：

```sh
npx tsx scripts/validate-lesson-markdown.ts "候选.md" --baseDir "真实课例目录"
```

命令只读，使用编辑器同一正文和数学解析器，不格式化、不改写、不提交。默认从候选文件所在目录解析附件；候选放在暂存目录时，用 `--baseDir` 指向真实课例资源目录。普通图片及 `cw-object-v1` 的相对资源路径均按该目录解析，必须存在、可读取且不越出目录。校验不执行组件，也不证明教学质量或教师已确认。

退出码：`0` 格式及引用附件通过；`1` 正文或附件无效；`2` 参数或文件读取错误。诊断格式为 `文件:行:列 说明`。解析器可能先报告第一个错误，修正当前候选后继续校验，直到通过。

## 当前明确支持的普通 Markdown

- 1–6 级标题、段落、粗体/斜体/删除线、链接、行内代码、单段引用、分隔线及闭合代码围栏。
- **平铺**有序或无序列表；不支持嵌套列表、任务复选框。需要层次时，撰写候选阶段用小标题和独立段落表达相同内容；不能对教师现稿静默扁平化或删改。
- 简单管道表格，分隔行使用 `---`。不支持 `:---`、`---:`、`:---:` 列对齐语法；合并单元格、题注等复杂表格使用正式对象表示。
- 独立成段的图片引用，指向课例目录内的真实附件；不是网络图片下载工具。
- 行内 `$…$`、独占行 `$$` 围栏数学。支持分式、根式、上下标、求和/乘积/积分、`aligned`、`cases`、`matrix` 等[已定义数学集合](../development-plan/R19_SHARED_DOCUMENT_CONTENT_CONTRACT.md#4-数学支持集合)；不接受任意宏包、自定义宏或整篇 LaTeX。
- 复杂对象必须使用现有严格 `cw-object-v1`；未知字段、任意 HTML、未闭合语法和未知数学命令直接报错。该围栏不是嵌套列表的替代格式，正式列表结构仍为平铺。

现稿校验失败时，在**当前原生任务**中定位并修正当前候选，保留教学内容与已确认阶段；若表达结构需要改变，应保留草稿并由现有确认流程处理。最终仍通过宿主当前文件版本校验（CAS）提交，校验通过不能替代提交回执或教师确认。不得靠改根 Schema、绕过诊断、另建正文、重生成前阶段或隐藏旧稿来宣称可确认。
