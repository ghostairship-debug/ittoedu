## 恢复方法

1. 将归档解压到普通临时目录，读取 `manifest.json` 中目标工作树的 `baseCommit`。
2. 从本仓库在一个新的空路径创建该基准的 detached worktree。
3. 在新工作树应用对应 `changes.patch`，再将对应 `untracked/` 的内容复制到相同相对路径。
4. 按需恢复 `evidence/`；这些文件只用于查阅历史。不要直接在当前主线上应用旧补丁。

基准提交均属于当前主线历史；删除旧工作树和六个同基准分支不删除这些提交。
