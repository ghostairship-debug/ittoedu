## 门审计的具体取舍

- HTML source 对照改为实际原文比较；不重复 Hash 全部文档来证明普通修改正确。
- 源文件版本、目标 binding 和最终 CAS 保留：它们直接防止当前源文已改变时错写，不是审美/固定格式门。
- 本地资源内容摘要用于资源身份与复用；稳定 item/block 标识中的摘要用于身份；操作票据摘要用于原操作身份与参数不能被替换。它们不作为一般导入正确性的额外门。
- 文档/成果未知发布的候选身份与内容版本继续用于原操作查证；只在实际发布结果未知时使用，不因每次普通交付新增通用字节/Hash 门。
- 已知 HTML、脚本和当前资源闭包能由正式载体承载即保真进入；软件维护 Runtime 包装与登记。实际外部资源、未知能力和不能运行的显式拆页条件仍给具体诊断；没有静态截图替代必需互动。
