## 6. 分层

划分标准：主机生成、放大或丢失的内容算软件问题。产品实际读给模型的 Skill 让它多走弯路，算 Skill 问题。没有这些文本和回执、模型仍会做错的内容，算模型错误。

### 6.1 软件

1. 正式回执把整页变更送回模型。这是 MCP HTTP 400 和内置 13,580,590 input token 的直接来源。测试 cut 没有模型回执投影文件。
2. 作者 HTML 被换成浏览器计算样式后再落盘、再送回模型。
3. 第 79 条 `context-summary` 没有把第 80 条动态请求限制在摘要本身的规模。
