本轮目标是使本次 Unit 1「YOU & ME」的内容设计、视觉和互动完成度能够在无预制策划、无成套素材时被主动生产，同时恢复正式分页、自由导航、持续编辑和稳定交付。软件承担身份、装配、导航、资源、事务、保存、执行调度和导出优化，模型集中于内容、设计、素材语义与必要局部程序。

1. 持续导航在全局层设计一次外观，复用已有教师控制器背后的正式翻页、跳转、进度与按键能力；保持本次或相近的定制体验，防止回退为默认教师控制台。

## 附录 A：写入现有 Skill 的 MD 参考

下面是设计方法的参考骨架，不是强制表单，不以字段齐全代替内容质量。

```markdown

## 整作设计

## 视觉与素材

## 场景：……
作用与前后承接：

```

**密度示例：认识 Mia（自拟人物与台词，不作教材原文）。** 初始标题为 “How can we get to know Mia?”，右侧人物插画，左侧 Name、Age、Country、Class、Spelling 五卡；为总结预留正文区域。点击卡片分别显示 “My name is Mia.”、“I’m twelve.”、“I’m from China.”、“I’m in Class Two.”、“M-I-A. Mia.” 并播放该角色对应语音，再次点击可重听。五卡均打开后，预留区域出现 “ASK → LISTEN → ANSWER” 和 “We ask questions, listen, and learn about each other.”，帮助学生从独立信息形成认识人物的方法。卡片状态只控制本场景总结，全局导航随时按正式能力工作；返回保留运行进度。人物作为可复用资产，文字和关系线保持可编辑，下一场介绍新朋友承接这一关系。

此例说明应确定真实文案、初始状态、操作、后果、素材与承接；五张卡、五句声音和全部翻开触发都不成为通用配额。软件负责资源、播放和页面接线，MD 不写内部 ID 或工具操作清单。
