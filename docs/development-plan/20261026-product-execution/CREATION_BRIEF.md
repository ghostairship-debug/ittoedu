# 城市夜线：完整创作对照任务（冻结版）

请为普通成人读者创作一件中文互动作品《城市夜线：把四站送达》。这是虚构配送场景，不是实际导航或经营建议。作品应能从故事开头走到完整结尾，让读者直观看见“里程短”和“按时送达”之间的取舍。

## 共同素材与事实

20:00 从仓库出发，服务四个站点。示意地图不要求按真实比例，但顺序、路线、数字和当前结果要一致。

| 站点 | 最迟到达 |
|---|---|
| 医院 | 20:20 |
| 社区 | 20:30 |
| 市场 | 20:40 |
| 书店 | 20:55 |

- A 线（最短里程）：仓库 → 市场 → 医院 → 社区 → 书店；各段距离依次 2.0、3.6、1.8、2.2 km，总计 9.6 km。
- B 线（准时优先）：仓库 → 医院 → 社区 → 市场 → 书店；各段距离依次 3.5、2.5、3.0、3.4 km，总计 12.4 km。
- 速度可在 12–24 km/h 之间调节，默认 18；每站停留可在 2–6 分钟之间调节，默认 3。
- 第 n 站到达分钟数 = 累计距离 × 60 ÷ 速度 + (n−1) × 每站停留。到达时间不晚于该站时限即准时。比较基于未四舍五入的分钟，显示可四舍五入到分钟并说明。
- 数据全部是本任务给定的假设，不能暗示来自现实调查。

## 交付承诺

由你自行决定结构、视觉、布局和正常推进方式。自然滚动或普通继续按钮均可。需要完整开头、过程解释、路线比较、实际可操作的速度/停留调整和有结论的结束；结尾应读取读者当前的选择和参数。不要把作品做成只有一张图或一个孤立控件。

用清楚、美观的地图/图示、可读的正文和相称的数据呈现支持理解。图示可以自己制作；给定的是数据，不是现成版式或模板。可按需借鉴已有参考，也可拒用。不要为了形式增加无关素材或额外互动。

1440×900 和 390×844 下正常阅读与操作；内容不能缩成小幻灯片。主要正文、标题和图像/图示能被准确定位并局部修改；模拟参数和共享计算源码可继续修改，范围外内容和人工修改应保留。首次交付要保存、可独立重开，并得到真正离线可运行的单HTML。后续另给一次局部修改，不计入首次创作时间。

尽量在十分钟内形成满足这些要求的合格作品。超时继续完成，不把首存、首导或局部成功当整作合格。不调用本机外部模型Agent，不启动新付费渠道。

## 对照路线

- H：交付直接编写的独立 HTML，允许同目录资源，但最终单 HTML 离线可用，后续通过当前源码局部改。
- G0：使用果铃现有正式工程/工具和按需参考，交付 GLX 与官方离线 HTML，并兑现所承诺的人工与 AI 续改。内容表达粒度由实际耦合和编辑需要决定。

两路线使用相同输入、同一内置模型及推理档位、独立新会话，先运行 H 后运行 G0。作者不得读取另一条路线的成品。准备环境和输入的时间单列；创作、素材、采用、保存、导出、必要修复时间计入各自首次合格交付。性能脚本与两条创作不在同机同时运行。
