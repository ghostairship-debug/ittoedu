## 可直接使用的文件

固定目录：`output/S2-acceptance/`。

| 文件 | 用途 |
| --- | --- |
| `S2-分数验收.h5lesson` | 在编辑器打开；26 次正式 Builder 工具事务生成 4 个 Surface、6 个位置，覆盖三种表面、单选互动、动态 Component、Flow 表格与 Spatial 路径/关系/镜头。 |
| `S2-分数验收.html` | 独立浏览器离线查看相同课例。教师控制器默认折叠，先点“展”；跨表面后按实际状态展开。 |
| `可编辑分数.pptx` | 真实 PPTX，含两段文字、四个形状和一个内嵌图片。浏览器实际解析确认得到 7 个可编辑对象和 1 个素材。 |
| `分数与可编辑表格.pptx` | 同页分数内容与普通表格，预期 8 个可编辑对象与 1 个素材。 |
| `可编辑表格.pptx` | 纯普通表格输入，应生成一个可编辑 Native Table。 |
| `多母版与表格.pptx` | 四页按 A/B/A/隐藏装饰排序，包含两个母版及其版式、继承标题和普通表格；共享修改只影响对应引用页。 |
| `应提示的合并表格.pptx` | 1.5 尚不支持合并区域，明确显示合并表格原因；该纯表格输入没有可用内容，不写工程。合并能力已安排到 1.6。 |
| `小尺寸与分组文字.pptx` | 可复现的脱敏输入：6个可编辑对象，覆盖小尺寸同步、分组字体继承、单字符对齐、普通边框、圆角调整与流程矩形；边框简化先提示，不能跳过整个对象。 |
| `树状图导入复核.h5lesson`、同名 `.html`、`树状图可编辑导出.pptx` | 本机真实29页课件的复核副本，打开即进入原第1页；643个原生对象，可编辑PPTX再解析零新增跳过。保留67个复杂对象的已知遗漏，不能直接当作完整教学成品；原始课件未改。仅本机提供，不纳入仓库fixture。 |
| `材料示例.txt` | UTF-8 材料导入、搜索、引用与删除演练。 |
| `build.mjs`、两份输入 Markdown | 固定工程 fixture 的公开 Builder V2 输入。它们是工程验收材料，不声称是新的教学策划签署。 |

建议打开工程后另存为练习副本，下面操作都在同一副本完成。验收课例故意保留四处内容错误：选择题页的错误答案声明，以及最后演示表面的公式、图表正文与来源错误。它们用于检查定位与修复，不是给学生的正式教学结论。

## 明示边界

- PPTX 直接解析并映射为原生对象，无需安装 Office/LibreOffice。普通图文、线条、普通分组、裁剪、占位符与未合并表格属于当前范围；复杂分组变换、合并表格、图表、SmartArt 及特殊效果按页明确报告，教师确认后允许部分导入。不自动生成图片，不承诺 PowerPoint 全特性等价。字体替代、段落与表格样式简化须按实际课件复核。
- 样板改写当前提供普通 Native 页的文字槽位；带动态载体、交互或状态覆盖的参考页明确拒绝。
- 内容 QA 检查明确语法和可唯一比较的数据，不证明任意自然语言的学科正确性或来源真实性。固定演练中的 `答案：` 要填写选项原文，图表主张格式见复核文档。
- 固定 Component 通过文件树构建，因此还可能提示没有原 ZIP hash、缩略图或来源记录；这些提醒不表示组件不能运行。Spatial world Runtime 仍无正式动态宿主，工具明确拒绝；Spatial 动态内容使用 Component。
- OpenMAIC 未采用，不阻塞 S2。未发布安装包或对外发行，Owner 已确认 S2，授权创建 `v1.5.0` accepted 标签。
