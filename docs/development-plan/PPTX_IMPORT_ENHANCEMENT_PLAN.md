## 产品边界

- `.pptx` 直接解析并映射当前正式 Native 内容，不上传远程服务，不依赖 Office/LibreOffice 或商业渲染器。
- `.ppt` 使用已安装兼容软件生成临时 `.pptx` 副本，再走同一解析、预览、确认与原子事务。首个承诺支持的转换后端为 Microsoft PowerPoint；其他软件（包括 WPS）只有适配器与真实转换验证通过后才能列入支持矩阵。不得仅修改后缀或把选择器放宽当作格式支持。
- 不覆盖原件、不安装软件、不执行宏/OLE。没有受支持转换软件时明确提示由教师另存为 `.pptx` 后导入；这种缺失不影响普通 PPTX 导入。取消、超时、损坏和密码保护零工程写入，清理当前转换临时文件，不终止用户已有软件会话。
- 不恢复自动 PPTX→PDF→整页图片链，不引入远程转换服务。源包已有 WMF 的显示解码与可编辑 OLE 公式转换是不同能力；本轮排入可编辑公式转换，不擅自把公式作为图片完成验收。
- 预览按源页和对象分别报告未支持内容、样式简化、动画/转场省略；不得把旧公式笼统报成图表，更不能用部分导入掩盖普通对象的映射错误。
- Native、Published 与适用导出的表达必须一致。优先复用现有载体；必要的字段扩展必须先独立定义 additive strict 合同，再实施 writer 和各消费者，不创建 V10 或第二 PowerPoint 工程模型。

## 修复前真实课件证据与统计口径

## 共享内容与实例映射

- 一个输入文件导入独立Slide Surface，保持源页序；母版/版式公共装饰使用surface共享层与精确location visibility，占位符实例正文留在scene，不污染课程global或原Flow/Spatial。
- 继承按对象实际角色和slide/layout/master/theme适用规则解析，普通文本框不能套用正文占位符样式；分组递归展开时保留子对象继承上下文及文字/描边缩放。
- 可表达的连续共享底层可导出PPTX母版；前景和遮挡例外保持按页输出，不为复用母版改变叠放。
- 表格使用唯一正式模型；合并区域、下标/形状/渐变若需新增字段，按各节点的合同先行约束实施。暂存源身份与转换中间文件不进入Published。
