# 1.8 短操作与可靠结束实施记录

2026-09-09。按用户“开始执行”授权实施当前 A/B/C/D 执行包。本批实现与受影响的代表性工程检查已完成；通过范围和保留失败如下，不代表 103 完整矩阵或 1.8 发布验收通过。改动基于 `c839c205`，保留工作区已有方案、报告和其他未提交文件；未提交、推送或发布。

## 已集成的行为

- 图片正例改为有效 PNG，原坏字节独立保留为负例。首轮观察区分附件缺失、解码/预检失败、不支持和未知；正式图片变换仍生成新资产并只更新目标引用。
- 能力发现按 operation/mode/Surface/owner/carrier 定向返回完整卡片，组件实例与共享 patch 使用正式目标。混合页优先保留选区必需卡，完整页面和资源仍可按需读取。Builder 复用同源发现、观察和回执接口。
- Codex 在创建 thread 前传入已选模型；稳定的输出 Schema 保留请求身份校验。真实 usage 的 last/total、推理和未知值贯通持久化与界面；机器候选和原生 userMessage 不作为聊天正文或工具活动展示。
- OpenCode 解析分组模型目录；目录查询按工作目录、CLI 版本及非秘密配置身份缓存、合并并发请求，界面区分加载、空目录和错误，并可刷新。已确认本机原生目录能返回模型，不能把分组解析问题冒称本机模型缺失的完整根因。
- 模型目录刷新保留同一身份下的原生配置确认，不将目录默认值冒充当前会话配置；目录暂时不能表达已确认值时明确显示未知，保留空目录与错误语义。
- version 2 短候选引用本轮目标别名与已有资产别名，由宿主从冻结请求绑定身份并展开为完整候选，再进入原有 prepare 和资源事务。资产引用使用显式 `$asset`，与前序产物 `$result` 分开；错误别名、范围、版本及迟到结果仍被拒绝。
- 实际 committed/unchanged 回执与 afterCommit 共同决定结束；预览仍等待应用。必要 observe 保留具体理由和新观察，动态 smoke 的 requires-review 不代表互动语义已完成。记录失败时保留已知回执并只重试保存；原生待送回执在下一次真实请求接受后确认送达。
- 同一个 20 分钟绝对期限覆盖发送前观察、原生运行、准入和应用前检查；停止和旧异步结果不能复活任务。连续失败的进展判定忽略随机身份、摘要、注释和格式变化，仍区分实际参数、源码语义及依赖变化。
- 动态准入失败的行为证据进入下一轮观察资源，提示只引用可读取的暂存文件，正式记录仍保留完整失败帧。修复了失败分支未传帧、两份内联截图容易超出续轮文本预算的问题。
- Codex 恢复原生会话时只接收元数据，避免不消费的历史回传触发输出上限。超时反馈按实际回执列出已完成阶段、当前未完成操作和重新观察恢复点；回执待保存时明确只补记录。
