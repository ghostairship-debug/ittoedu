# IME（中文输入法）人工验收操作单

目的：验证「用系统输入法打中文」与「拼音组合输入中按回车/斜杠」不误发、不误开菜单。
背景：产品使用系统输入法（微软拼音/搜狗等），无需任何产品改动；难点仅在自动化（OS 级组件无法在 CI 复现）。本单由人工执行一次并留档。

## 前置

- 用 `npm start` 或已构建的应用启动（真实窗口，非 E2E 后台模式）。
- 系统输入法切到中文（微软拼音或你惯用的）。
- 打开任意工程 → 打开「创作助手」聊天面板（或工作台内嵌聊天）。

## 步骤与判据

1. **普通中文输入**
   - 在聊天输入框用拼音打一段中文（含选字），如「平均分是分数的前提」。
   - 判据：候选框正常出现；选字后文本正确进入输入框；无丢字、无重复、无错位。
2. **组合中输入回车（关键）**
   - 打 `pingjunfen`（拼音尚未选字、候选框开着）时按 **Enter**。
   - 判据：Enter 只用于**选字**，**不得**触发「发送」；输入框内容不被提交。
3. **组合中输入斜杠（关键）**
   - 打拼音（未选字）时输入 `/`（或先 `zf` 再 `/`）。
   - 判据：`/` 作为普通字符进入组合串，**不得**弹出 `/` 命令菜单。
4. **组合中空格/数字选字**
   - 用空格或数字键选字。
   - 判据：选字正确；不触发任何快捷键行为。
5. **@ 输入**
   - 打 `@`（英文半角）→ 判据：出现 @ 引用菜单（若产品支持）；打中文全角「＠」或拼音组合中的 @ → 判据：不误弹菜单。
6. **发送后清空**
   - 正常发送一条中文消息 → 判据：消息出现在记录中，输入框清空，无残留组合态。
