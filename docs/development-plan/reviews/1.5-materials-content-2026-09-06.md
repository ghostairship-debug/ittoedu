# 1.5 材料与内容生产力复核

材料、受限 PPTX、样板改写和内容检查均通过现有 V9 内容与资源事务接入，形成 S2 工程候选。S2 未签署，不创建 `v1.5.0` accepted 标签；可直接复核的文件与步骤见 [S2 验收单](../acceptance/S2-tools-and-materials.md)。

## 用户入口与支持范围

- “创作工具 → 教学材料库”：粘贴文本、导入 UTF-8 TXT / Markdown / CSV、来源搜索、引用和删除。按工程 ID 与规范化文件路径隔离；另存为不复制旧材料。可见引用是普通文字，删除缓存不删除已插入内容。
- “创作工具 → 批量编辑与参考页 → 导入 PPTX”：先检查并预览页数、对象与转换说明，确认后追加新的演示表面，整包只产生一次文档与素材历史。首批支持显式几何、明确字号的水平文字、基础预设形状和内嵌 PNG / JPEG。对象与文本框保持可编辑，组合形状的文字拆为独立文本框。字体按当前系统解析，画布按原比例居中适配，文本框内边距归零。这是明确的受限转换，不宣称 PowerPoint 全保真。
- PPTX 按 Owner 2026-09-06 的补充决定改为部分导入：占位符、分组、表格/图表、无法转换的媒体或继承几何按页与对象跳过；动画、链接和部分视觉效果省略后保留静态内容，复杂背景回退白色。预览展示遗漏清单并允许确认可用内容；主文档不可读、资源超限或完全没有可用对象才停止。ZIP 限制为输入 32 MiB、展开 128 MiB、单项 32 MiB、4096 项、200 倍压缩比、100 页、2000 对象。图片须由真实浏览器解码。所有解析与资源准备留在暂存内存，不创建第二工程或磁盘写入路径。
- 同一面板的“样板改写”：选择现有演示页，每个原生文字对象构成明确槽位；预览列出来源、原文、新文和容量结果。缺槽位、超容量、过期预览或带动态载体/交互/状态覆盖的来源明确拒绝。确认后复用正式参考页身份与资源重映射，生成普通 V9 副本，整体撤销不改来源。新文字不会通过无限缩小字号塞入。
- “工程检查”：只读 finding 显示 rule ID、严重度、依据、建议与 canonical target。四类内容检查均为确定性检查，没有另设模型推理循环。

## 内容检查可判定范围

1. 数学：Native / Flow 公式 AST 的未填槽位与普通正文中 `公式：<线性公式>` 的语法错误使用 `content-math-parse`；真实共享公式布局器的警告使用 `content-math-render`。可访问文字不是线性公式，不把它误送入解析器。
2. 答案：单个明确的产品单选规则族中，正文 `答案：<选项原文>` 与实际有限选择 evaluator 比较。多个歧义规则族、带条件的任意手写交互或不透明扩展代码不推断正确答案。
3. 图表：正文 `图表：标题 / 系列 / 类别 = 数值` 与同一 owner 中可唯一定位的正式图表数据比较。支持 Native Chart 与 Flow Chart。普通自然语言不被当作可判定数值声明。
4. 来源：显式 `来源：` 的空值、待补标记、空定位，以及缺少 citation 的 Flow 引文给出定位提醒。不会把所有普通文字都判为必须引用。

这些检查不能证明任意自然语言的学科正确性，也不能证明来源真实可靠。教师仍负责最终内容复核；没有 finding 不等于学科审核通过。规则只使用可携带正文与既有结构，不添加隐藏 QA 元数据。
