## 1. 总体结论

现有前端已接通主要目录会话和文件入口，但尚不能认定 V3.1 完整交付。创作重开、布局连续性、重复聊天、拖拽方向及验证有效性仍有问题。优先完成创建、手改、AI 修改、保存重开、预览与导出的作品闭环；真实可用性问题先于框架整理和新格式扩展。

后续采用“**目录组织会话，当前内容提供默认编辑焦点，明确指令决定特殊目标**”的体验。聊天输入区以一条可点击的自动目标提示承接上下文，少用的选项按需展开。材料读取与必要策划融入 Agent 对话，用户可以直接提供文件、路径或粘贴内容。

本报告取代聊天中上一版汇总的“常驻当前文件下拉框＋编辑范围下拉框＋锁定按钮”设计。**默认当前页、点选后当前选择**的既定规则保留；此前提出的“默认全文件”已撤回。

## 2. 已确认的交互方案

### 2.1 会话归属与文件关系

- 会话归属工作空间或项目目录；同一目录可有多个独立会话、多个可编辑文件。
- 未打开文件时，以当前目录为默认工作范围，根据请求查找、读取和操作相关文件；不默认读取或修改全部文件。
- 会话可以先于 `.h5lesson` 存在。材料讨论、策划及未生成作品的任务必须可重开；文件生成并首次保存后继续原会话。
- 打开文件为当前会话提供编辑焦点，不自动切走会话，也不为每个文件复制一套聊天记录。
- 各会话保留自己的任务和决策；共享目录内的材料不等于合并全部聊天上下文。
- `.h5lesson`、Markdown 及未来支持原格式编辑的 Office 文件沿用共同的会话／目标原则；本轮不宣称 Office 编辑已实现。
- 各格式共用工作台标签、目标提示和任务反馈，各自负责真实读取、选择、编辑、保存与导出。分别说明“可预览、可引用、可编辑、可写回原格式”；转换成新课件与修改原件分开，转换结果如实标明可编辑、保留、静态化或未支持内容。

### 2.2 一条自动目标提示

聊天输入区显示简短、可点击的目标提示，平时无需操作。点击可以定位目标或展开低频范围选项，不常驻两个下拉框。

| 用户当前状态 | 提示示例 | 默认编辑焦点 |
|---|---|---|
| 没有打开文件 | 当前工作目录 | 当前目录内与请求相关的内容 |
| 正在查看课件第 3 页 | 串联电路 · 第 3 页 | 当前页 |
| 选中文字或对象 | 串联电路 · 已选 2 项 | 当前选择 |
| 清除选择 | 串联电路 · 第 3 页 | 回到当前页 |

**打开文件默认当前页；一旦点选，自动切换为当前选择；清除选择后回到当前页。** 点击聊天输入框不能被当作清除画布选择。全文件由用户主动选择或用“统一整个课件的字体”等明确指令指定。

默认目标跟随活动内容标签。任务发送后再切文件、翻页、换选区或改布局，只影响后续消息，不重定向正在执行的任务。任务状态与布局分离，收展、全屏和停靠变化不终止任务、不丢草稿或历史；浏览其他内容不被无关任务阻塞，对同一目标的冲突写入仍由既有 Owner 协调。

### 2.3 自然语言、引用与固定目标

- “这一页讲得再直观一点”：使用当前页；“把它们对齐”：使用当前选择。
- “参考 @教材.pdf，修改这一页”：教材是参考材料，当前页是修改目标。
- “把 @串联电路.h5lesson 的第 3 页改得更简洁”：明确指定该文件及页面，优先于活动标签。
- `@` 文件本身表示引用，不自动授予该文件“修改目标”的角色。输入区应区分修改对象与参考材料。
- 本条消息明确指定修改对象后，浏览其他材料不会改变它；目标持续可见，发送后随该消息保留。
- 跨多轮固定目标作为展开菜单内的低频选项，不设常驻全局锁定按钮；是否仍有必要通过交互样例检验。不能保留用户看不见的锁定状态。

目标解析优先级为：**本条消息明确指定的对象／范围 → 当前选择 → 当前页 → 当前工作目录**。只有存在实际歧义时才简短询问，不要求每轮确认。多个引用中谁是材料、谁是修改对象，以请求表达为准；无法确定时不猜测写入目标。发送时固定实际文件、页面／选择及当前版本；后续浏览不能改变本轮目标。目标被删除、替换或版本失效时由正式编辑链处理，不静默扩大为全文件或全目录；默认焦点和引用范围不替代原生 CLI 权限合同。

### 2.4 材料与策划融入对话

用户可把材料放入目录、告知路径、通过 `@` 引用、拖入附件，或直接粘贴文字／图片，然后说明希望得到的结果。导入、采用、策划不作为必须依次点击的独立步骤。Agent 按任务读取材料、分析需求、开展必要教学策划并生成或修改作品；缺少影响结果的信息时提问，用户要求先审方案时通过聊天或实际文档审阅，局部修改不被强制带入完整四阶段流程。

教学知识获得路径、材料真实性和结果质量要求继续保留。复杂创作可形成有价值的策划文件，不默认要求所有任务生成固定四份 Markdown，也不立即删除全部策划能力。用户应看见：**实际读了什么、准备完成什么、结果保存在哪里**。列目录、发现路径、建立索引不能声称已读材料；PDF／DOCX／PPTX 的真实读取与必要图示、出处及创作消费仍分别验证。

### 2.5 文件状态、修改反馈与工具展示

- **文件状态一致。** 标签、顶栏与关闭提示消费同一保存事实，区分未保存、保存中、已保存、冲突、失败及恢复稿；“AI 已应用”与“文件已保存”分别表达。
- **修改结果清楚。** 简洁显示改了什么、涉及哪些文件／对象及保存状态，提供查看与真实可用的撤销。只有宿主提交回执才能显示已应用；撤销复用正式历史，不能覆盖后续人工修改，外部工具写盘没有宿主历史时不伪造撤销入口。
- **保持自然操作。** 已授权的简单修改直接形成结果，不因增加变更反馈而每次再走预览／批准；确有歧义时才询问。复杂任务按真实阶段显示进度，支持停止和必要恢复，成功、失败、取消均有明确终态，不永久转圈。
- **工作台内编辑器继续减负。** 默认集中于内容、选择和高频文字／图片／移动／基础样式手改，对象属性随选择展示，高级状态／互动按需展开；不把近乎全量的编辑器工具栏和侧栏直接塞进工作台，选中对象也不自动挤走聊天。
- **编辑器模式单独打磨。** “在编辑器中打开”应提供适合精细编辑的工具分组、属性层级、空间分配和清晰返回入口，不只是放大全量 UI。两种工作位置共用工程、选区、历史、保存与任务状态，完整能力保持可达，不恢复简洁／专业能力分档。正常聊天保持人类可读，原始事件、JSON 和协议细节留在日志。
- **保留已确认布局。** 无内容时使用目录聊天，打开内容再展开；保留自由停靠与输入框上方紧凑的 CLI／模型／强度／速度配置，不照搬固定左右栏、AI／属性强制二选一或常驻多组上下文控件。

### 2.6 桌面 Agent 基础交互与项目／会话管理

- **消息可选、可复制。** 对齐 Codex 等桌面 Agent 的基础操作体验：用户及助手消息可鼠标选取、键盘复制，单条消息和代码块的复制按钮真实写入剪贴板；成功／失败反馈对应实际结果，流式更新不随意打断选择。聊天文本选择只用于文本操作，不替换内容页编辑目标。用户已反馈当前消息不可选择、复制按钮不可用，列入优先修复。
- **`/` 呼出命令与模式菜单。** 可搜索当前实际支持的会话命令、Agent 工作模式及配置入口；支持键盘选择、确认与退出，并明确当前模式和生效范围。复用已有原生能力与配置，不增加第二套模式状态，不把 Agent 模式混同于编辑器简洁／专业分档；输入法确认不误触发送，普通路径／文本不被强制当命令。
- **`@` 呼出引用菜单。** 查找当前目录中的文件、目录及已支持的页面／对象，显示可辨别同名项的路径信息；选入后引用可见、可移除，继续区分参考材料与修改目标，不把引用自动视为编辑授权。`/` 与 `@` 采用一致的搜索、键盘和空结果反馈，不要求记命令或手输完整路径。
- **项目新建与管理减步骤。** 从清楚的统一入口选择已有文件夹或命名创建文件夹即可开始工作，默认使用当前工作空间；不要求先建课件、跑流程或重复登记项目。切换、重命名及移出列表等常用操作就近可达，明确区分移出导航与删除磁盘文件，避免多层弹窗与重复树。
- **会话管理减层级。** 新建直接使用当前目录上下文；切换、搜索、重命名和归档／删除采用一致的就近入口，能准确找到指定历史，不能只自动接最近会话。清楚显示归属与运行状态，切换保留各会话草稿和任务，不隐式合并聊天或删除实际作品；具体摆位通过交互样例收敛，不预设再增加常驻面板。

### 4.1 文案与失效调用点（B）

- 目录语境残留“课例创作助手”“说明教学主题／编辑当前文档”；外壳还有“课例对话”“课例工作台”“资源与课例”、着陆页强制建立课例及“回到课例对话”。需按新体验统一。创作流程面板已有非目录会话条件，不计为目录分支泄漏。
- LessonConversationNavigation 仅剩测试引用；newStandaloneProject 无生产调用方；openLesson(true) 虽有 JSX 调用，但 openingCopy 没有置 true 的入口，实际不可达。清理失效 UI 前核对合同消费者，不直接删除仍有效的后端能力。

## 5. 未完成能力与验证缺口（E）

- 工作空间内自动完整权限尚未接线；“范围内完整权限／范围外默认只读”目前不是已实现的应用策略。原生授权往返及特定任务输入读取例外不能证明整个策略。

- 普通目录 Markdown 未接入完整文档 AI 上下文；当前目录聊天未传 documentTarget，普通 file ref 的 AI 修改仍被拒绝。
- 文档标签可关闭，固定课件标签缺少关闭入口。
- 未找到新路径的直接覆盖：全屏往返、四向拖拽、上下单实例、收展时草稿／任务连续性、＋新建 Markdown、DirectorySessionList 分支／删除、未生成课件的重开、项目目录实际对话。
- Shell／CopyOpen 单测及 editor、多个 r18、stabilization 规格仍有旧入口；CopyMove 整体跳过。删除旧 UI 对应测试不等于替代路径已覆盖。
- 多份 Luna 规格仅静态适配；五份指定会话规格退化为自动接最近会话，不能证明准确接续指定任务。
- Path B 仅验证 running／waiting-confirmation 后停止，未证明材料创作全链；规格缺少显式 Luna/Fast 选择及真实调用门控。目录 CLI 历史运行记录称通过，但当前断言不足证明真实答复成功。
- 新吸收要求尚需按实际路径核验：跨文件类型的保存状态是否一致，结果摘要与真实提交／撤销是否对应，停止／失败后能否继续，以及代表任务的阶段耗时。它们是待补证据，不把已有局部机制一概判为未实现。
- 新增桌面 Agent 对齐要求尚未逐项核验：消息选择／复制、`/` 命令与模式、`@` 引用菜单、项目新建与管理、会话查找与切换，以及两种编辑位置的工具密度；不能把本报告中的要求写成已支持能力。

## 6. 实施边界与验收

后续须按已确认体验同步总纲、前端方案、会话／文件合同与直接 consumer；本报告没有把现有 lessonId 强绑定、四阶段 guard、原生会话隔离或外部 Skill 停点自动改成新规则。保持一份正式会话记录、唯一工程真相和正式编辑事务，布局变化不重建文档会话或历史；首次保存继续目录对话，Save As 建立新的文件编辑目标，旧候选、目标 epoch 与项目专属执行句柄不能直接继承。目录讨论与新文件编辑记录须在同一正式合同中落实，不复制第二套会话库。

实施顺序：先解决创作连续性、保存、历史可达及消息复制等当前可用性问题，同步补齐目标／结果反馈、桌面 Agent 基础交互和项目／会话管理；两种编辑位置的 UI 随真实操作持续打磨。有耗时证据后优化速度，新增格式沿既有路线推进。组件拆分以职责与生命周期问题为依据，不按文件行数或未来假设定级，不把新增 Provider／TaskCenter 本身当成交付。

性能优化复用现有计时、输入计量与按需能力发现，按冻结任务／材料／模型配置比较原生启动、读取、生成、候选修复和提交；分别报告首次正确可用结果、全任务结束、失败及人工干预。优先减少已证实的无关输入、重复读取和无效往返；生成物文件大小不等于模型输入量，首屏时间不等于整课完成。不照搬外部报告的固定秒数、重复次数或百分位门，也不新建性能平台。

提速保留原生 CLI 模型循环、工具、Skills、权限及正式事务，不另建受限 Agent；修复或文件候选兜底依据实际错误与原有任务预算，不硬编码“修一次后强制切换”。同一有效候选的既有证据按受影响范围复用，验证须直接证明行为、持久化或真实视觉结果。

长期文件扩展沿[既有产品研究](../../../果铃_AI原生文件与内容工作台_产品方案_V2.0.md)采用格式适配和成熟内核，先验证显示、目标定位与可靠写回；不建立万能 Schema，不延后已承诺的 PPTX／三格式材料／Word 路线，也不将 Office 深编辑设为当前前置。具体供应商、授权、PoC 和版本排期仍属后续研究，尚未立项。

最小验收场景：

1. 无课件文件时讨论、读取材料，关闭重开后继续，并首次生成保存作品。
2. 当前页 → 点选后当前选择 → 清除选择后当前页；进入聊天不丢画布选择。
3. 同目录多文件，分别执行“改选中对象”“参考另一份材料改当前页”“修改整份课件”；目标提示、材料角色及实际改动一致。
4. 本条消息指定目标后查看其他材料；发送后切文件、翻页、收展、全屏和四向停靠，原任务目标、草稿与历史连续，聊天始终单实例。
5. 首存、Save As、历史查看、保存失败及重开形成实际闭环。
6. 直接提供路径／附件／粘贴材料，完成可编辑、可保存、可重开、可运行及适用导出的作品；失败读取如实反馈。
7. Markdown 与课件分别核对保存中、失败、冲突、恢复稿和保存成功；标签、顶栏及关闭提示一致，不把已应用误报为已保存。
8. AI 修改后能定位真实改动，并经正式历史撤销／重做；停止、失败和重试有明确结果，后续手改受到保护，界面不永久显示运行中。
9. 对承诺转换或原格式写回的文件，分别验证显示、选择、修改、保存及原软件重开；未改部分和格式能力声明一致。性能任务同时保留正确性、耗时及失败证据，不用启动状态或首个候选代替正确成品。
10. 用户／助手正文及代码块可选择、复制并实际粘贴核对；流式消息可操作，失败不假报成功。`/` 和 `@` 支持搜索、键盘与输入法，切模式实际生效，引用角色、归属及编辑目标保持清楚。
11. 无课件时选择或新建项目目录并直接对话；多项目、多会话中准确找回指定任务，切换后草稿和运行状态连续，管理动作不误删文件或合并会话。
12. 工作台内完成常用轻改，编辑器模式完成精细编辑并返回；在常用及窄窗口实际检查工具密度、焦点、遮挡、拖拽和内容空间，工程／选区／撤销／任务连续。无页文档的焦点表达、低频固定目标及语言目标提示时机通过样例细化，不改变当前页／当前选择默认规则。
