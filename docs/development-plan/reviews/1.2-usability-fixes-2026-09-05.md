# 1.2 用户可用性修复复核（2026-09-05）

本轮修复用户补充的三组问题，并处理共享绘制/颜色路径上的已知反例。基线为 `9b5fc73`，修复保留在当前工作区，未提交、发布或创建标签。采取实施合同 §11 的验收补充加直接实现；单执行者单会话不创建任务卡。

## 交付结果

| 用户问题 | 结果与实现边界 |
| --- | --- |
| 文本背景无效、无法取消高亮 | 共用 Native painter 消费背景色、alpha 与圆角；在原背景完全透明时选择颜色会使其可见。清除高亮保留既有必填 nullable 值，不把它当字段删除；基础和命名状态可保存重开，其他可选字段的删除语义保留。 |
| Table/Chart 只能在属性栏改文字 | 双击表格单元格编辑，Enter/Tab 提交并移格，末格文本与追加行共用一次事务。图表标题、分类名和系列名可在画布编辑；分类/系列编辑与属性栏现有整表草稿一并校验提交，非法草稿保留且零写入。 |
| 无选中边框、不能缩放、拖动不跟手 | 选中框和手柄读取正式 V9 图层几何；拖动和缩放直接更新 Published Native 临时预览，松开才一次提交，取消恢复。没有扩展 legacy SceneNode 或新增持久化图层。 |
| 添加组件还需再次放置 | 内置库和外部导入入口完成校验后直接创建当前合法画布实例并选中。包与实例同一事务，已安装同版本同内容的包复用；异步目标失效、包冲突或批次失败均不留下半包/半实例。复用既有 Slide、Flow 和 Spatial 插入命令，未新增容器权限。 |
| 拼音属性说明竖排 | 组件布尔属性的说明跨完整内容列，脱离 checkbox 窄列；修复通用属性布局，无需修改拼音包。 |

共用路径同时修复：表格填充/边框 alpha；pie/donut 单一非零值的整圆/环及零值伪线；bar 多画折线与自定义轴越界；图表轴、网格、数据标签和四向图例；颜色 Undo 后重选无效；背景预览缺失 owner/继承与会话身份。图表数据仍由正式 Native 数据和现有属性草稿持有，新增桥接仅连接回调。

## 实际行为证据

1. **作者画布与历史**：完整 Renderer + Published Player 的 Chromium 操作确认表格、图表拖动期间位移分别跟随指针 `80/40`、`-75/-45`，松开后与预览一致；9 个手柄可见。表格缩放途中 Esc 恢复原尺寸；图表缩放后 Undo 恢复。另在表格拖动 `50/30` 期间切换到全局层再松开，返回场景后恢复原坐标，单次 Undo 直接撤销表格创建，证明被取消的手势没有新增历史。表格末格提交后行数 3→4，单次 Undo 同时恢复旧文字和 3 行，Redo 恢复 4 行。图表属性草稿保留数值 42，再在画布修改分类名，两者一次提交；单次 Undo 同时恢复旧分类与数值 10。
2. **文字与组件**：启用高亮后取消，实际 span 背景为透明；选择红色使文本框背景为 `rgb(239, 68, 68)`，Undo 与重新选择均有效。真实拼音包从库添加一次即出现并自动选中，Undo 移除、Redo 恢复；两段布尔说明实际宽度均为 273 px，高度分别 14.5/29 px，正常横向换行。
3. **保存、重开、运行、HTML**：通过完整 App 的保存→新建→打开，确认拼音组件、表格文字“表格保存后保留”、图表标题“图表保存后保留”、红色文本背景和已取消高亮全部保留；当前位置试运行一致。通过实际导出入口生成单 HTML，经普通静态服务器独立打开，四类内容正确、控制台 0 错误/警告。导出夹具刻意重叠图层，已知重叠提示按 UI 继续导出。
4. **图表边界视觉**：正式 painter 的 pie/donut 各 `[100]`、`[100,0,0]`、`[0,100,0]`、`[20,30,50]` 共 8 例实际截图确认整圆、环孔与扇区正确；单一非零数据只绘制一条有效 path，外框均为 140×140，零值不产生径向伪线。

浏览器夹具只替换桌面文件/对话框端口与本地组件目录，使用真实 App、正式工厂/命令、包资源、工程序列化和 HTML 导出器。它不证明 Electron 原生文件对话框或 `file://` 双击路径。拼音以同机组件目录中的真实 `.h5component` 加载。独立导出核验发生在最终零值扇区调整前；该调整随后由正式 painter 视觉与针对性测试复核，Player bundle 已重新构建。

截图、实际 `.h5lesson` 和 HTML 位于本机 ignored 目录 `output/playwright/review-9b5fc73/`，主要文件为 `fixed-pinyin-full-app.png`、`fixed-chart-canvas.png`、`fixed-pie-donut.png`、`fixed-reopened-player.png`、`fixed-exported-html.png`、`fixed-ui-roundtrip.h5lesson`、`fixed-ui-export.html`。这些是辅助证据；下列正式测试和本文场景可随源码交接，不依赖临时目录才可继续开发。

## 后续收尾：input 与连续颜色

F1 已实现：新增“填空题”直接创建输入框、两个普通反馈文本、独立答案/有效性状态键与正式规则族。文本支持 1–15 个规范化答案，数值采用含端点范围；创建、配置、类型切换、复制、删除均走作者事务。复制携带受管理反馈并重建稳定引用；删除专业规则或反馈时在同一事务解除失效规则族管理。键仍有外部引用或无法证明无引用时保留并提示。专业手改采用显式保留/重建，列表外规则不删除。

运行端从正式 Published descriptor 绑定 input；提交先完整校验并一次写入答案和有效性，再匹配规则。静态/作者宿主不写状态，IME 组合 Enter 不提交，Esc 恢复输入草稿。PPTX 保留可编辑静态填写区并给出交互边界提示；实物解析发现默认 CSS 字体列表导致 XML 无效，已复用正式 PPTX 字体转换修正。
