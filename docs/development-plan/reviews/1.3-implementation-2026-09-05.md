# 1.3 实现与复核

## 交付范围

- 六种 Recipe 从同一 catalog 展开为普通 V9 页面、声明式交互或现有 Component；可见入口位于“创作工具”。排序携带真实 Component 包，资源与页面一起进入单笔历史。
- 参考页克隆限定当前工程 Slide；批量文字替换和项目色应用提供范围、逐项预览、勾选、过期拒绝与整体撤销。颜色控件直接读取项目既有色板。
- Chart 的独立 strict 合同允许 Flow 正文与 Spatial world，共享数据编辑、SVG painter 和属性视图；Table/input/global 不扩域。Flow DOCX 使用静态图面与可编辑数据表。
- 快速诊断复用原有 health collector，增加文字容量和单选答案一致性，按严重度与 Surface 展示并定位对象。

## 实施方式

Chart、Recipe、生产力分三个隔离工作区并行，主线统一接线、诊断与能力索引；子智能体交叉审查实际 diff。移除参考页/批量替换对 Recipe 的人工依赖；固定布局与容量阈值取代排版求解器；不引入第二工程模型、诊断系统或主题状态。

## 验证证据

- 主线类型检查、Player 与 Renderer 构建通过；整合后的五个目标文件 47 个用例通过，覆盖 Recipe、生产力事务、跨 Surface Chart 与能力索引。
- 子分支合同 63、图表相关 consumer 98、新增图表及草稿桥接 16 个用例通过；Recipe 与运行控制器 40 个用例通过。交叉审查修复了 Spatial 属性入口、strict 内容适配、缩放编辑坐标、IME blur、打印 margin 和 DOCX 高图适配。
- 真实桌面用例“活动文字草稿：Slide、Spatial、Flow 不失焦保存并可重开”通过（57 秒）。未重复 1.2 已通过且未受影响的整个桌面套件。
- 真实 UI 验证封面直接编辑、批量替换及 Undo、项目色仅应用勾选项、参考页克隆与整体撤销；原页对象保留。Spatial 验证拖动、边框缩放及 110% 视图拖动。
- 真实 UI 验证逐步揭示的鼠标/键盘推进和重进重置；选择题的错误/正确反馈和重新选择；排序的错误判定、真实列表重排、正确判定及重进恢复原顺序。
- 实际浏览器生成五类 Flow 图表 PNG 和 DOCX；DOCX 内五张有效图片与五张可编辑数据表，超高图面按页面空间缩放。制品保存在 `output/playwright/r13-docx/`，不作为源码提交。
- 真实 UI 发现并修复两项自动化漏检：选择重绘替换 SVG 节点导致双击失效；画布 frame 与属性 item 地址导致草稿桥接不相通。Spatial 实际确认属性值草稿与画布文字一次合并，属性栏同步且无待应用草稿。
- 最后复审修复单选诊断只跳场景、不选选项的问题；按对象实际归属定位，场景与全局选项定位断言通过。诊断/定位/颜色三个文件 35 个用例通过，目标集成文件修复后 3 个用例通过。
- Flow 未选中图表的首次双击已实测进入编辑并同步属性；高度拖动由 360 变为 436。新增 SVG 节点保留、frame/item 共用草稿目标两条回归通过。最终类型检查和 Renderer 构建通过；Player 未受最后作者态修复影响，沿用本轮构建证据。
