# 1.6 开发与验证记录

2026-09-06。实现与验证已完成，源码候选为 `v1.6.0-rc.1`。Codex、Claude、OpenCode 最新真实 CLI 复验均通过；本版为 engineering candidate，不声明 accepted。

## 已实现

- Main 独占的 CLI executable 解析、无 shell 参数启动、允许环境变量、目标进程树取消；Codex / Claude / OpenCode 协议适配与统一八类事件、严格 IPC 输入输出。保留 CLI 自身的工具与插件配置，不读取凭据文件。按 Owner 本轮决定，OpenCode 的应用默认模型为 `opencode/big-pickle`。
- 单一 harness 管理不可逆终态、会话恢复、输出上限和异步分批落盘；按既有 WorkspaceIdentity 隔离的版本 1 本地记录、损坏隔离、删除与中断恢复。没有向工程模型加入 session/trace，没有工程写入器。普通构建关闭服务；受控进程设置 `COURSEWARE_CLI_DOGFOOD=1` 才开放现有 preload 的 `localAgent` 操作。1.6 不提供聊天 UI。
- Native Table 与 Flow Table 的 strict 矩形合并合同、非空正文汇入锚点、拆分、结构变化拒绝及复制身份重建；Slide / Spatial 属性和 Flow 正文编辑接线，Published、Native 布局、PPTX 合并单元格与 DOCX `gridSpan` / `vMerge` 同步。合并后的多行正文按换行绘制。
- PPTX 合并表格、主题与可表达文字样式；真实 `.ppt` 经本机 Microsoft PowerPoint 创建临时 PPTX 副本后复用现有预览/确认导入流程；文字下标与翻转的 strict 可选字段、作者/Player/导出消费者；图片 `clrChange` 本地转换与原素材保留。
- 两次合同先行提交为 `3ea189c`（表格合并）和 `9124d7c`（文字基线与翻转）；其后实现通过独立工作树整理为本版源码候选，未混合提交此前已有修改。
