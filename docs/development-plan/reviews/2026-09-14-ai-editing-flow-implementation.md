# AI 修改流程简化实施记录

2026-09-14。状态：本批工程实现及聚焦验证完成；不代表美术接受或版本 Owner 验收。

对应 [实施方案](../AI_EDITING_FLOW_SIMPLIFICATION_PLAN.md)。本轮只使用 Luna，真实调用的 requested / sent / confirmed 均为 `gpt-5.6-luna`、medium、priority；未调用其他模型。

## 已落地

- 按 Owner 追加决定，正式 candidate v1/v2 **删除** `lowerCarrierReason` 字段，提示、示例、helper 不生成它。只有传输入口丢弃旧字符串或 null；不存在“仍需写理由但不阻止提交”的流程。其他未知字段及无效输入继续拒绝。
- 内联与文件交付统一规范化：工具 input 的 JSON 字符串只展开一次，坏 JSON 和双重编码有明确诊断，源码和文本内部的字符串不被递归改写。
- 现有 candidate-helper 支持从冻结组件描述准备工作副本、计算改变/删除文件并生成正式 patch；ID、版本与基线由冻结快照提供。同源 input Schema 在本地预检，合法结果引用延后到宿主解析，空补丁在本地提示无需提交。
- 全局组件多页准入复用真实播放器会话。相同源码、实例、有效覆盖与尺寸复用生命周期检查，仍逐页/状态切换、更新输入、取得实际帧；不同 Surface 分别检查。切换后排除仍留在 DOM 的隐藏表面，恢复后重新取得挂载实例。行为点击保留完整导航环境；普通固定目标检查使用可丢弃的范围投影，绝不写回正式工程。
- 大素材以二进制跨 IPC 传输，由独立准入会话按需提供资源 URL，不再把所有图片/视频 base64 塞进控制 JSON。动态素材调用保守保留可能依赖，真实请求缺失素材仍报错；独立进程完成后释放资源。计时器由主进程持有，完成一个实际目标才延长单目标期限，绝对任务期限和取消继续有效。
- `afterCommit: finish` 直接结束，不再因通用 `requires-review` 标签强制开观察回合。视觉或点击任务由实际候选请求继续观察，不为追加总结单开回合。
- 独占可编辑包原位修订并保持包 ID；共享或原始包的实例编辑才派生。十次修订不增加一串包，Undo/Redo 同时恢复源码与资源。未扫描删除用户库中的历史包。
- 请求路径为绝对路径，组件提示与稳定 ID 规则同步；同一全局实例不会在 20 个页面描述中重复列出源码编辑目标。等待信息依据原生工具开始/结束事件和最近活动时间，不从模型文字猜测是否在执行工具。
- 恢复教师控制台继续只在属性的折叠维护区管理，播放界面没有恢复按钮。本轮没有重新引入旧原生渲染逻辑。

保存验证有一项**测试脚本故障**：第三项在点击保存后立即关闭窗口，磁盘仍是基线 revision 4。已把脚本改为等待保存完成；使用已经生成的同一份 Luna 源码，通过正式组件 patch/资源事务做一次不调用模型的回放并完成保存，保留旧文件与回放 receipt。重开 revision 5 后，20 页、57,671,680 字节无关素材和原包 ID 均保留；这证明序列化及运行结果，不记作原始 UI 保存首遍成功，也不计作模型重试。

重开后实际点击：目录第 20 页可导航且目录自动收起；重播仍重播当前页；回到第 1 页后下一步进入第 2 页；缩放、折叠/展开正常。课件缩放为 1.5 并平移后，控制台位置与尺寸保持不变。实际截图确认蓝色纹理及可读文字；风格仍待教师选择。
