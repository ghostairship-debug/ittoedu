## Performance protocol

- Run `5` warmups followed by `21` measured process-cold launches, each with a new empty temporary profile and no recents/recovery.
- Use a normal visible packaged window. Start the timer immediately before launch; shell is `.app-shell` visible; first editable means a non-zero Slide/Flow/Spatial authoring surface is visible and New/Save controls are not busy.
- After first editable, wait `1s`, record aggregate `peakWorkingSetSize` for all Electron processes in bytes, close normally and confirm process exit before the next sample.
- Median is the sorted middle sample; P95 is nearest-rank. Start sampling once and do not rerun to select better values.
- Raw samples go to ignored output without username, hostname, PID or absolute profile paths.
