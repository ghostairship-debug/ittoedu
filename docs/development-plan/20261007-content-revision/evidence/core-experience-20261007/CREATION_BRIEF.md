# 三路共同创作材料

任务：《串联电路：一处断开会怎样》。面向小学高年级，三个教学页面或连续讲义中的三个清晰教学段，约五分钟使用量。三路作者均为 gpt-6-luna / medium，各自独立决定内容、布局和实现，不共享成品。自动推进并保留策划和框架产出，无需等待阶段确认。

共同事实：一个电池、一个开关和两只串联灯泡只有一条通路。完整闭合时两灯都亮；开关或任意一处断开时两灯都灭。只讨论理想开关和断路，不涉及短路、电压或亮度计算。

教学目标：辨认单一路径；先预测，再操作并解释断路结果；完成一道带即时解释的判断题。

关键互动：开关可重复切换，两只灯泡同时亮灭，解释随状态更新；提供复位；另有一道判断题和即时反馈。图示或模拟由作者自主实现，不能以截图代替真实互动。

共同图像要求：每路作者通过同一既有账号的 GPT OAuth 图像连接，新生成一张课堂桌面上电池、开关和两只小灯泡的实物教学插图，用于情境引入。请求方形、不含文字、PNG、中等质量、不透明背景，size:auto，记录实际尺寸。作者自行写提示并调用各自正常公开能力；至少一张新图片实际嵌入，交付后引用有效。旧图、SVG和占位不能替代；中断先查原作业并复用成功资源。

MCP 在正式工程内自主调用公开 MCP；内置 AI 从真实产品聊天入口沿已授权 Luna 连接执行；裸 HTML 作者自主写 HTML/CSS/JS 并运行，图片使用相同产品连接。不得 Root 代写精修、隐藏身份注入、内部 handler、受控 provider 回放或 DeepSeek 替代。

首次任务交付包含作者任务内正常检查修订，须单独保全；事后软件修补和人工救场另记。计时到作品可打开并实际使用，包含图像等待、装配、资源和保存，另列图像耗时、实际模型/推理/计费回执及人工干预。质量比较内容教学表达、画面可读布局和真实关键互动；可编辑性/撤销/保存重开另列。发行暂停。
