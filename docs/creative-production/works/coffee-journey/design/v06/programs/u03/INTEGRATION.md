# U03 组织比较｜参考源码与装配说明

本目录提供 U03 局部程序的可执行参考源码，不自行代表整件作品的正式交付版本。完整 GLX、正式离线 HTML、版本与真实验收结论，以作品的交付 Manifest 和创作收口报告为准。

## 正式装配入口

`u03.html` 是局部程序装配入口：CSS、交互脚本、比较/详情所需 SVG 均已内联。由果铃既有资源与统一事务链将下列三份既有图片闭包后，修改当前 GLX 的 U03 程序源码；不要覆盖全篇 HTML，也不要修改 U05。目标实例必须从当前工程读取，不复制历史实例 ID。

- `assets/natural.webp`
- `assets/washed.webp`
- `assets/honey.webp`

图片沿用 `docs/creative-production/works/coffee-journey/design/v05/assets/` 中原件。正式参考源包已补齐这三张照片；生成脚本本身不生成或复制它们。迁移时若漏掉这些文件，直接打开 `u03.html` 会缺图。相对引用必须由既有资源/导出流程闭包，或在装配输入中换成对应图片 data URL。已有正式 GLX 的内嵌资源不因此要求重新导入。

## 修改入口与生成关系

`build_u03.py` 是本参考源包的生成入口，仅依赖 Python 标准库。运行 `python build_u03.py` 会覆盖同目录下的 `u03.html`、`u03.css`、`u03.js`、`content.json` 和三份 `assets/*-layers.svg`，不会修改任何 GLX。运行前保留这些文件中的独立手改。

| 要修改的内容 | 在 `build_u03.py` 中的入口 |
| --- | --- |
| 三条路线的标题、文案、组织状态及步骤 | `methods` |
| 剖面几何、颜色、组织保留与图形材质 | `diagram(mode, prefix)` |
| 桌面/手机排版、照片呈现、控件和局部阅读底 | `style` |
| 并排图、四层矩阵、详情和单独观察的结构 | `photo`、`buttons`、`compare`、`rows`、`templates`、`html` |
| 选择、详情、比较、返回、键盘与高度上报 | `script` |

`u03.css`、`u03.js`、`content.json` 和独立 SVG 是便于按需检索的**生成副本**；生成脚本不会读取这些文件。只编辑这些副本不会自动更新内联的 `u03.html`。改写本参考时应修改对应生成入口并重新生成，再通过正式事务将局部程序应用到目标 GLX。普通工程续改仍以当前 GLX 为唯一作者事实，不从参考 HTML 整体重建作品。

独立 SVG、比较 SVG、详情 SVG 使用 `asset-*`、`compare-*`、`detail-*` 三组不同 ID 前缀，以避免多个内联实例的渐变、纹理和无障碍标题发生冲突；图形几何与绘制内容保持一致。

## 本轮改变

1. 以相同几何与尺度的组织剖面比较三条路线：红色果皮果肉、琥珀色黏液、浅金色羊皮层、绿色种子。虚线只表示去除的外层位置。
2. 并排模式直接呈现三幅结构图，配四层状态矩阵；图内无需要缩小阅读的文字。
3. 详情图使用同一矢量语义，以 DOM 图例显示组织、保留状态、处理步骤。
4. 手机排版配置为三列结构图与对应状态矩阵，说明文字保持独立排版；实际 390 px 正式工程验收见作品收口报告。
5. html/body 背景透明，不声明强制 color-scheme；仅结构卡片与矩阵留局部浅色阅读底。

## 保留的状态契约

- 初始路线 `natural`；点击或键盘切换只改变选定路线。
- 详情展开状态独立于选择；选择其他路线时详情内容同步更新。
- 进入比较保留选定路线及详情展开状态；返回恢复它们。
- 比较和返回保留现有 `coffee:reveal` 协议；高度通过现有 `coffee:height` postMessage 上报。
- 箭头键循环选择，Home/End 选择第一/末项。
- 只在切照片时进行 CSS 过渡，减少动态模式关闭过渡；无持续 rAF 动画。
- 此局部程序使用独立 U03 脚本，不加载或改写共享 `lab.js` 的 U05 烘焙部分。

## 源包检查与正式工程验证的边界

- 已通过 JavaScript 语法、SVG XML、DOM/SVG ID 唯一性与三份已知图片依赖检查。
- 已核对 CSS/JS 导出与 HTML 内联逐字一致、`content.json` 与运行数据一致；三份独立 SVG 与比较/详情 SVG 除 ID 前缀外一致。将生成脚本放入空目录重新执行，七份输出与本目录逐字一致。结果见 `SOURCE_CONSISTENCY.json`。
- 三幅 SVG 经 sharp 实际渲染并目视检查；正式手机结构与矩阵截图见 [完整比较](../../previews/coffee-390-u03-comparison.png)，三种组织保留差异直接可辨。
- 最初源包检查所在的本地环境缺少 Playwright 浏览器二进制，因此本文件不将那次本地页面状态或手机截图记为通过。该历史限制不表示正式 GLX 验证尚未完成；最终实际结果以作品收口报告为准。
- `verify.cjs` 是可选的独立页面状态复现脚本，要求本目录已有三张照片、可解析 `playwright` 包且已安装兼容的 Chromium。它不能替代正式 GLX 的事务、保存、冷开或离线验收，也不作为本参考的运行时依赖。

不声称通用多方案比较组件。改写其他主题时需替换形态、组织定义、状态矩阵和路线文案；可以复用“同尺度图形＋同维度矩阵＋单独/比较状态保留”的机制。
