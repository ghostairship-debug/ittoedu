## 实际精修

原生章节文字组与 Scene Runtime 同时控制大背景，是 U04→U05→U06 色块割裂的直接原因。七组正文背景改为透明，大背景由唯一 Scene Runtime 调度；文字的进入与退场消费同一 phase，并通过正式暂态 motion 改变呈现，不改正文或持久化 opacity。暖砂→褐→深炭、深炭→绿→淡绿保留章节气质，过渡与主体动作同步。

桌面保留主视觉与正文的空间关系。390px 将正文下限提高到13px、导语14px，按主体分别配置位置与尺度；文字退场的过渡区将主体向中间移动。修复开篇杯子与注释碰撞、烘焙标签与底部场景说明接近的问题。并非七章使用同一张版式。

烘焙观察点采用520ms缓变；拖动仍即时响应。局部程序在离屏、后台和suspend时停播。无效隐藏变换、未变样式写入得到收敛；场景仍按阅读、布局与实验事件绘制，无持续空闲RAF。

## 源码与修改入口

GLX内保留三份可编辑Source定义及其依赖，47个原生文字对象和七章结构。此次可读源码位于 `output/coffee-final-20261025/source/`。Runtime统一视觉与材质；原生Flow负责阅读结构；三个局部控件写共享语义状态；导航程序调用宿主正式阅读导航。

## 非阻断边界

- 390px为桌面Chromium模拟视口，不是实体手机认证；长时间移动设备热降频和长时内存压力未专项认证。
- 仪表中的rAF时间含宿主调度/离屏节流，存在重复时间戳，不作为FPS成绩。
- 局部控件直接销毁而全局运行仍保留时，最后一次active状态可能残留；正常离章/暂停路径已验证停播，本轮没有发现该条件被正常阅读触发。作为可复用组件时应明确局部销毁契约。
- 科学过程、液位和烘焙关键帧是解释性示意，不预测实际温度、时间或萃取动力学。

正式样本自本次冻结后不再承担体系实验。组件提炼与新作位于独立的 runtime-first-system-20261025 目录。
