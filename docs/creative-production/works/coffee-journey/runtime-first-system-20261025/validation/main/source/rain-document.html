城市观察 / AFTER THE RAIN

雨落城市

同一场雨，为什么留下
不同的街道？

雨停以后，屋檐仍在滴水。有人绕过积水走回家，另一条街的草地却悄悄接住了雨。差别不只在雨下得多不多，也藏在我们铺了什么地面、给水留下多少位置。沿着一滴雨的去向，把街道看成一段仍在工作的剖面。

01 / 水没有消失

先找去向，再谈快慢。

落到街区的水，可以进入土壤，也可以先留在低处或设施里，剩下的再流向外部。这里把三条去向叫作入渗、暂存和外排。它们描述的是同一场雨的分配，不是三种互不相干的水。观察任何一种去向，都要同时看看另外两种发生了什么。

为了把关系看清，我们暂时把复杂城市压缩成一个解释模型：每条街区都收到一百单位降雨。不透水比例越高，模型允许的入渗越少；蓄存空间决定有多少水可以先留下。外排是扣除这两部分后的余额。三个数始终相加为一百，变化的是分配，雨量本身没有改变。

入渗像向下打开的门，暂存像留出的一段缓冲。二者可以同时发挥作用，也可能被不同条件限制。把全部希望放在一种设施上，容易忽略街道作为整体的关系。

02 / 把街区交给你

让两条街，接住同一场雨。

先比较“透水改造”：两边的地面和蓄存条件都不同。再切到“只增加蓄存”，把地面条件固定下来，你会更容易分清改变来自哪里。也可以拖动四个滑杆，自行寻找外排相同、内部去向却不同的组合。数字与色条会一起变化；每一格颜色都属于同一笔水量账。

不要只追求一个更小的外排数字。先试着只改一个变量，再改另一个，最后一起调整。这样得到的比较，能解释“为什么不同”，也能看见同一种结果背后的不同组合。实验中的地面与水箱是示意图，颜色条才严格对应这次计算的比例。

03 / 街道之外

留下来，还要有下一步。

暂存不是让水消失，而是把它的下一段旅程推迟。真实城市还要考虑水随后去哪里、设施怎样恢复容量，以及下一场雨来临时是否已经腾出空间。我们的模型没有表现这些时间过程，也没有描述土壤、坡度和排水网络的全部差异，所以它不能用于工程预测。

这个实验提供的是一种提问方式：一块新铺的硬地，把水交给了谁？一个下凹的绿地，接住的水还有没有出口？一条街的改善，又会怎样与周围街区相处？带着这些问题走回雨后的城市，井盖、路缘和树池就不再只是背景。

给雨一点留下来的空间，
也给城市多一种选择。

从一块地面的改变出发，理解水的整段旅程。你不必在这张图上找出唯一答案；能说清一次调整改变了哪条去向、哪些条件还没有被计入，就是下一次观察的起点。
