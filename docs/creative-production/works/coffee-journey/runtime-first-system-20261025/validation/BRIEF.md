# 独立双路径创作共同任务 · 雨落城市

## 内容目标

为普通读者创作《雨落城市：同一场雨，为什么留下不同的街道？》。使读者理解降雨会在入渗、暂存和外排之间分配，并通过实际参数比较两种街区。正文约700—1100中文字，具有完整起承、机制解释、实验与有意义的结尾；章节数量与形式自定。允许为清晰表达适当调整字数，但不得以削减内容或实验换取十分钟数字。

## 视觉与互动

独立于咖啡的艺术方向：雨夜纪实感或城市剖面可作为起点，由创作者自行发展；至少一项合适的真实媒体素材（授权摄影或明确标注的生成媒体均可）与原创动态解释。避免固定七章、换图换字、默认配方卡片堆叠。主要正文为果铃原生可编辑文字，必要耦合标注可保留局部程序。1440px与390px阅读/实验均可用。

两街区对照实验：可调不透水比例p∈[0,1]与蓄存能力c∈[0,40]，至少两个有解释价值的比较状态；数值、动态图形和解释一致。共同示意模型：总降雨100单位，I=60(1-p)，S=min(c,100-I)，R=100-I-S；I/S/R分别为入渗/暂存/外排，总和100。标清这是解释模型，不是工程预测。不要伪造地理/水文数据。
