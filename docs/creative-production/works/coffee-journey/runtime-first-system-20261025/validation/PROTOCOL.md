# 双路径验证口径

## 固定条件

共同任务见BRIEF.md；资产使用ASSET_INDEX v1.0，包括通用背景包与方法、零雨城成品。两路径自主决定结构/视觉/素材/代码，可拒绝资产。主Agent不读取Luna正文、源码或画面后再创作；准备期仅查看运行身份、计时与工具状态。

Luna：生产Electron UI单次Send，runId 3c9aa018-242f-422b-8bcd-1897add77501，gpt-6-luna / max / OpenAI OAuth。最终核对完整请求actualModel，不依赖模型自述。必要图像由独立媒体角色生成，其模型另记。原配置未启用vision角色，此轮不途中更换。

主Agent：当前主Agent通过DevSpace远程客户端连接果铃正式MCP；不直接写GLX、不以独立HTML代替正式工程。与Luna使用相同需求和资产。主Agent作为资产作者具有先验熟悉度，两路径模型与调用方式不同；这是实际工作流对照，不是隔离变量的模型排名。

## 计时

使用同一远端主机时间记录各T0与终态，宿主计时内部采用同clockInstance的performance.now差值。不混减ChatGPT工具时钟与远端系统时钟。Luna T0取send-attempted.json的实际Send前标记；主Agent从开始本题具体策划计时，包含思考、素材、代码、全部远程往返、重试、观察、正式保存导出。

模型请求历时包含队列/服务等待/生成与传输，不能称纯推理时间。工具内部执行、累计工作时间与区间并集单列。无法测出的主Agent模型时间不以总时长减工具时长冒充。首次保存不等于首次可用；没有对应画面/互动证据时，首次可用时间写未独立测得。

十分钟同时区分：①十分钟内形成完整GLX和官方HTML，后续只读验收通过且无需改动；②十分钟内连同必要视觉、互动、独立冷开、离线验证全部完成。只有基础结构、首存或可预览程序均不算达标。超时继续，不弱化内容、互动与编辑要求。

## 原始结果与辅助

Luna首次终态复制为luna-original，10分钟附近保存当时状态并记实际采样时刻，不能把稍晚采样称精确第600秒。实际保存/导出回执时间用于定位产出。外部只读验收不改变原始作者归属；任何指导、代码/视觉修订或软件条件改变都另记，保留原结果。

观察器曾使用旧包装，现改为当前正式execution.run读取；checkpoint.record只是持久化检查点，不能冒充实时Run。监测修正不重置T0、未重发任务、未改作者工程。前期空快照不是Luna成品。构建/资产摘要在T0后早期采集，mtime早于T0仅作为旁证；最终比较相同摘要只能证明采集区间一致，不夸称预先完整冻结。详见conditions-luna-start.json与MONITOR_NOTE.md。

## 质量判断

共同硬要求：逻辑完整；主题独立；合适媒体；正文原生编辑；p/c两参数与I/S/R模型一致；至少两种有意义比较；1440/390可读可用；正式保存、独立冷开与离线交互可靠。美感判断看实际构图、文字层级、图片质量、主题表达、动态解释与阅读节奏，给具体画面依据，不以FPS、工具成功或模板复用比例代替。

通用滑杆/生命周期复用不等于模板化。固定叙事槽位、默认配色卡片或缺乏内容意义的装饰才是需要说明的问题。不以重写代码多证明创造性。

同一雨城题可对照两条路径并检验咖啡经验迁移一次；不足以证明跨任意题材的稳定10分钟能力。正式推荐资产保留更广泛实用验证门槛。
