# 用户指南

本指南对应当前 main 的工程候选，正式课件使用 Project V10。旧 V9 工程不通过当前正式课件入口兼容转换，保留原文件；源码内的旧类型或历史测试不表示软件承诺支持它们。已验证范围和未完成项见[当前状态](development-plan/CURRENT_STATUS.md)。

## 工作空间与文件

双击 `启动果铃工作台.cmd`，打开实际课程资料目录作为工作空间。工作空间、文件目标和会话彼此区分：打开文件不替换目录会话，删除聊天或会话也不删除用户文件。

课件编辑、工作台和专注视图使用同一工程。新建、打开、选页和选对象从当前界面入口进行；恢复稿与正式磁盘文件分别保存状态。只在用户要求保存或交付已保存文件时写入正式文件，成功应以实际路径、当前/已保存修订和 dirty 状态为准。

原生工程扩展名为 `.glx`。当前 V10 的原 `.h5lesson` 仍可打开；新建和另存使用 `.glx`，普通保存保留现有文件路径。新名称和图标不迁移账号、配置或恢复稿。

## 编辑与创作

演示与空间保存自由位置、编组和顺序；讲义保持正文阅读顺序。局部文字、图片、样式、frame 或互动修改保留未选内容和人工布局，确认后进入正式 History，可按实际支持操作 Undo/Redo。

新课以工程为作品：策划→工程内框架→素材与软件装配→关键页/互动检查→交付。策划和框架默认各等教师确认；已明确授权自动推进时照常产出阶段成果但不等待。不要先生成外部整课 HTML 再重导入作为内部新课创作流程。

已有外来 HTML 使用保真导入入口；软件处理资源、身份和可编辑登记。局部问题保留可用内容与清楚诊断，不用截图或静态化替代尚需运行的内容。缺少媒体连接时如实说明，不自动转向新收费供应商。

## 观察、保存与输出

预览/观察显示实际运行结果；提交成功不表示已看过画面，截图成功也不表示完整互动已验证。用户要求保存时显式保存，冷开读到的结果、实际导出物与工作中的恢复稿分别说明。

当前交付服务支持单 HTML、网页包及适用的 PPTX、PDF、DOCX 投影。格式对程序内容的捕获或专业数据保留程度不同，消费真实导出报告中的 warning/定位信息；不要把所有格式称为无损可编辑。

## 外部 MCP

后台宿主可在无需工作台主界面的情况下启动，指定绝对 workspace，使用软件返回的实际 endpoint 和连接配置。相对文件名按宿主 workspace 解析。客户端 detach 不关闭共享宿主；专用宿主经正常停止保留事务和恢复事实。

教学方法见[编排 Skill](../.agents/skills/orchestrate-courseware/SKILL.md)，局部修改见[edit-content](../.agents/skills/edit-content/SKILL.md)，外来 HTML 见[导入 Skill](../.agents/skills/build-courseware-project/SKILL.md)。旧用户指南保存在[历史正文](archive/README.md#历史原文)，不按它的旧协议、界面或 CLI 路线开展当前工作。
