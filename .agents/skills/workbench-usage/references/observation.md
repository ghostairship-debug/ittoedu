# 运行与观察

需要视觉判断时观察实际目标及邻近受影响范围；用当前观察入口和本次读取的页面路径，不改变教师当前页面来获取截图。需要互动证据时执行核心操作并看实际反馈及必要重置。局部改动只检查受影响范围，关键页有效证据可复用。

实际画面、互动、提交和保存分别报告。观察失败、超时或未返回图片时说明诊断与缺少的证据，源文或成功应用不能当作看过画面。不重复同因调用，不为简单改字机械检查整课。

`view.observe` 按回执的 `source`、`identity`、`coverage` 说明实际载体和范围。当前课件路径重建隔离 Published 画面，可证明对应呈现；现场双击、输入草稿与正式提交须用真实编辑入口，程序私有状态须观察对应会话或动作序列，导出性能须查看实际导出文件。这些证据不能互相代签。

素材独立预览只能说明它在该预览中的逻辑与绘制；正式页中的尺寸、滚动、控制台遮挡和变化后的反馈，需要在正式工程或其实际导出消费者中观察。已有 HTML 观察动作可以检查实际导出页面，不必读回全量 HTML，也不要修改导出 HTML 后再重导覆盖工程。只有初始图或独立素材自检时，如实说明尚未观察的嵌入互动状态，不宣称整体通过；按当前受影响范围选择必要检查，不为每次编辑额外导出。

组件程序使用当前宿主提供的运行接口和生命周期。Provider Secret、原始 Electron Main、任意 OS 命令和未开放宿主 API 不属于组件权限；外来代码不继承文件或登录权限。
