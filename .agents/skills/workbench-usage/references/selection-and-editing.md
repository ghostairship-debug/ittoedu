# 选择与局部编辑

当前任务已绑定的文件、页面和精确选区是起点。已有完整内容快照与可写目标时直接给替换内容；内容不完整或修改含义不明才补充读取。相同文字不能让另一个只读选区变成写目标。软件维护授权目标和冲突检查；读取 Skill 不增加写权限。

短选区修改用当前提供的文字或内容入口，不需要加载课件创作方法。普通 HTML 文件沿用源文编辑；课件页、对象或源码修改按需读[工程内文件](project-files.md)。不要改外部整课 HTML 后重导覆盖人工修改。

内容与排版范围由用户决定。局部修改保留未选内容、顺序、人工布局和未涉及行为；共享定义与当前实例源码是不同范围。若写入冲突，保留这次输入并重读受影响目标再修。正式身份、History、资源绑定与保存状态由软件维护，模型不登记编号或抄修订号。
