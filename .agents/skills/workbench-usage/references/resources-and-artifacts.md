# 资源与成果

先看任务目标、现有资源及本次真实可用能力，操作指南不规定所有图片必须先搜或先生成。图片搜索涵盖已接入来源实际支持的照片、插画和已有图示等，不将非照片自动改为手绘 SVG；生成/编辑使用本任务已配置连接和实际参考图能力。能力未知、未配置或不支持参考时准确说明，不盲试空角色或另开收费路径。来源和已有授权事实随资源保存，交付说明必要来源/署名；网页可访问不等于已获复制/发布许可，未知不得伪称开放授权。

`image.search {query:"所需图片"}` 检索已接入图库；网页搜索/阅读发现来源页后，用 `image.search {source:"来源页完整 URL 或 web.open 返回的 sourceId"}` 读取该页图片事实，两种输入择一。结果提供真实候选句柄、来源页、作者、已有许可和尺寸，图注与图片创建日期有则返回；网页发布日期不当作拍摄日期。未知或不符现许可政策的图片只返回来源与排除原因，不产生可下载候选；`allowShareAlike:true` 只用于用户已明确同意 CC BY-SA 的情况。有限图库或单页无候选不表示互联网无图，也不能把来源页 URL 直接传给 `image.fetch`。

图库和来源页候选都可用 `image.preview {images:["实际候选句柄"]}` 查看，再用 `image.fetch {image:"实际候选句柄",path:"本次工程读取的页面或对象路径"}` 应用。图片对象表示原位替换，页面表示插入；替换保留人工位置与图片效果，来源、许可与署名随素材保存。省略 `path` 得到本任务资源，可在 `project.apply` 的 `from` 使用；不自行编造 assets 路径或拼资源编号。图像生成与计算返回的资源也沿用实际回执。

`image.preview` 也可读取本任务获授权的图片资源或整张工程图片句柄，预览不重新生成。需连续角色/场景时，用 `image.edit {prompt:"本次画面要求",references:["稳定角色参考的真实来源或句柄","必要场景参考的真实来源或句柄"]}`；按实际需要传一张或多张，不只在文字中声称“参考上一张”。`references` 接受当前可读取的图片 `source/resource`、材料图片或工程整张专业图片/图片素材句柄，宿主读取原字节；参考来源与可选 `target` 独立。无参考的新图用 `image.generate`，该入口没有 `references` 参数。支持生成不等于支持编辑/多参考，按本次冻结能力和真实回执判断，不承诺绝对一致；来源选择属于任务方法，不设搜索或生图次数门。图片 ready 不等于已写入工程，后续应用/保存需真实回执，工程续用不能依赖临时任务仍存活。

材料图片及当前已授权 MCP 下载/二进制结果返回的 `source` 可直接使用，授权本地文件路径也可作为来源。`media.insert {target,source}` 在已观察页面插入图片、音频或视频；`media.apply {target,source}` 原位替换同类型媒体，保留对象身份、人工 frame、专业效果和未指定字段。可省略插入 frame，由宿主按媒体尺寸放置。页面或整课背景用当前配置入口的 `background.source`。来源原样传给内容入口，软件读取字节、登记资源并提交，不要求先保存临时中转文件或拼资源身份。

组件库检索返回可用条目，用已观察的页或对象路径取用。软件处理依赖和身份；选区提炼只在用户要求时存入库，使用任务绑定范围或明确对象路径。未知信任按实际回执和现有组件库入口处理。

用户明确生成并插入或替换时，`image.generate/edit` 添加 `application:{mode:"insert"|"replace",target:已观察句柄}`，软件固定目标，生成成功后一次正式应用；普通 `target` 仍只绑定文档，不推定替换。未给 application 得到候选；给了 application 则分别读 generation、application 和 save 回执，不能仍要求模型重复生成或搬运候选完成同一次应用。生成期间同目标人工变更或停止不覆盖，已有图片保留，可按当前授权续用；应用不意味着文件已保存。

`asset.search {packageId,version?}` 读取已找到条目的真实对象、rootIds、页面及可改输入；`asset.use {packageId,path,rootIds?}` 可插入完整条目或选定对象子树。`asset.save` 沿同一库服务提炼对象(默认)、页面(`scope:"page",path`)或课程结构(`scope:"structure",pages:[实际页面路径]`)；软件映射新页面、内部导航、状态及依赖，保原人工内容和主题。未知程序内部页面不能仅按预览未访问就裁剪。

受限计算使用当前计算能力，点名获授权输入与所需输出；不以未授权 shell 或安装依赖替代。等待或查状态只沿用返回的 `job`，不另外选择作业类型；作业 ready 表示成果可用，还未写入用户文件。交付用户选定输出用 `artifact.save {source,destination}`，`source` 直接取创建、状态或等待回执，用户决定目的地；软件处理来源身份及保存，报告引用实际返回路径。无需保存中间缓存，不猜或拼 job/resource/name。未返回成功保存时说明真实状态，结果未知沿原操作查证，不重发作业。

新增工程内容中的相对资源由工程入口解析实际闭包。局部资源问题保留原件和其他可用内容，按诊断修复；不截图静态化。文件交付语义见[文件与保存](files-and-delivery.md)。
