# 发现与当前可用性

本轮实际提供的工具定义是调用依据，已有入口直接使用；`tools.load` 不作为任务前置或能力可用性的证明。接口已登记、生产启用、连接配置和本任务权限是不同事实，静态索引只说明登记。未配置原因按实际结果说明，依赖缺口只影响相关部分；不循环空调用或虚构结果。

内置或已授权用户/工作区方法用 `skills.list/read` 按需发现与读取。选择当前任务方法，不让短编辑读完整创作方法。共享指南是独立 `workbench-usage` 根，使用目录返回的完整名称和根内路径；读取脚本只是内容，不授权执行。

外部客户端使用宿主提供的同源工具和当前连接配置。静态能力索引或外部 Builder 的 discovery 仅在对应环境已提供时按需查询；不拿历史名称、计划或另一产品根推断当前能力。没有工具时说明缺口，不自行调用未开放宿主接口。
