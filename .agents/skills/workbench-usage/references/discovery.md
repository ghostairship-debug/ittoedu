# 发现与当前可用性

新作设计需要选择表达方式时，可按需读取软件同源提供的能力概览。已有明确文字或格式目标时，直接使用目标正文、相关格式及当前工具，不先读取整工程、能力地图或源码教程。场景状态、空间与镜头、全局背景、导航、动效、专业节点与局部程序在任务需要时展开；完整所需Source可直接读取，无须先让常规入口失败。概览由宿主按冻结范围、权限与配置裁剪，Skill不另维护实时可用性清单；注册、允许、已配置和实际执行成功仍是不同事实。

本轮实际提供的工具定义是调用依据，已有入口直接使用；`tools.load` 不作为任务前置或能力可用性的证明。接口已登记、生产启用、连接配置和本任务权限是不同事实，静态索引只说明登记。首轮已给出的正文、属性和常用布局直接使用；专业内容、互动、媒体、Office、外部服务或委派缺少入口时，再按本轮目录调用 `tools.load` 展开相关族。软件把真实工具参数接入后续请求，加载不授予额外权限，也不代表连接已配置。未配置原因按实际结果说明，依赖缺口只影响相关部分；不循环空调用或虚构结果。

未被用户主动限制的新任务默认使用最高档 `full`；用户明确选择的模式和旧任务冻结范围继续有效。模型可在该范围使用正式编辑、Source及文件能力，不因Skill未加载、工具未展开或输入形式而另行申请普通作者操作。高层入口遇到问题时，读取具体错误、实际目标和可修路径，沿已有源码/文件入口完成修正；当前确实不能生效则保留输入并报告缺少的能力。最高作者权限不把Provider Secret、原始Electron Main或任意OS权限交给被导入的组件程序。

内置方法随工作台提供，无需外部安装；已提供方法与本任务已读取的方法是不同事实，读取方法不解锁软件能力。内置或已授权用户/工作区方法用 `skills.list/read` 按需发现与读取。外部同名方法用目录返回的 `user/` 或 `workspace/` 完整名称明确选择来源，内置方法仍用原名称。选择当前任务方法，不让短编辑读完整创作方法。共享指南是独立 `workbench-usage` 根，使用目录返回的完整名称和根内路径；读取脚本只是内容，不授权执行。

已知工具名可用`tools.load {names:["实际工具名"]}`精准展开定义；需要一类能力时仍可按family加载。未披露不表示无权，普通`read`默认返回语义正文，显式`detail:"object"`可读完整对象；完整Source及依赖按实际引用直接读取。

外部客户端使用宿主提供的同源工具和当前连接配置。静态能力索引或外部 Builder 的 discovery 仅在对应环境已提供时按需查询；不拿历史名称、计划或另一产品根推断当前能力。没有工具时说明缺口，不自行调用未开放宿主接口。
