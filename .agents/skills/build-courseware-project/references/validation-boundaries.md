# 与任务结果对应的检查

`course.createFromHtml` 负责其声明的导入、保存与交付，模型读取任务结果，不重复编排内部保存调用、转抄版本号或把每次操作的机械回读作为新的创作回合。没有实际保存结果时不宣称已交付工程。

用户只要求导入时保留原作品；创作任务需要实质内容和核心展示机制。模型的观察用于具体的知识、视觉或交互问题，先检查相关区域及受影响内容，复用仍然有效的证据。无需默认逐页截图、审美打分、全仓回归、无关导出或清理旧文件。

已有作品的局部编辑沿用当前正式编辑与保存能力。只有生成了替换内容而未实际应用时，明确它仍是建议或候选；保存、重开与导出的状态按当前真实回执分别说明。软件检查通过不代替用户的视觉和教学验收。
