# 初稿、局部精修与完整验收

## 默认初稿

复用宿主编译、资源闭包和真实载体准入；文件必须有实质教学内容、核心图示／示范及已经承诺的主要展示机制。导入后立即保存，核对真实保存版本、dirty 状态，并从文件字节回读场景和资源。空壳、只保存来源 HTML、仅 recoverable 都不能代表所请求的课件交付。

默认不逐页向模型发送截图，不自动评分配色、微调坐标，不做未被请求的全部导出或清理旧用户文件。明显启动错误、缺失资源和隐藏页由软件机械检查报告；具体失败需要修正时可以观察该页。

## 人主导局部精修

只处理用户指定的页、对象或文字。需要时观察当前版本，修改后检查实际变化，保持未要求修改的页、稳定身份和正式 History。活动文字、图文轻编辑、保存与撤销语义不因初稿模式减少。

## 用户要求的完整检查

按本课实际使用的能力验证主要路径、关键互动、必要重置和导出。教师演示允许正常翻页；自主学习才核对必须的条件与分支。只复核受影响的行为，已有有效证据可以复用；不跑全仓回归，不为每份课件重新测试软件所有故障分支。

交付分别说清已保存内容、机械检查、人工教学／视觉判断与缺失项。工程完成不等于教师 accepted；也不因为未被请求的审美检查没做就让可靠初稿永久 partial。
