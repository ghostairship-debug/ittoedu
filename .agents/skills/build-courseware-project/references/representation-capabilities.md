# 当前内容承载方式

- 普通静态 HTML/CSS：解析为 Web 组合，保留元素、文本、样式、布局关系与资源引用；软件登记身份，不把所有内容重写成手填坐标的 Native。
- 专业内容：可选短组件表达可以把图表数据或语义正文交给现有原生能力，外围仍用普通 CSS 布局。未使用组件的第三方内容照常导入。
- 程序内容：需要共同运行的脚本、事件与状态保留为 Runtime，不能承诺任意内部对象均有原生属性面板。
- 现有作品：Slide 有自定义宽高；Flow 有连续文档排版；Spatial 有世界与相机。不要因内容可以复用而声称任何作品都可自动无损转换呈现方式。

调用 `course.createFromHtml` 时由宿主完成具体承载和交付。内容需要修改才由模型作出新的设计决定，不另写表示规划或整库能力报告。
