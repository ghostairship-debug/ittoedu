# 表示选择短能力简介

框架生成需要承载边界时读取本短说明；不因此展开全套 Schema。默认不创建表示规划文件，已有明确映射由导入器完成。

- 演示页 Slide：固定画布，适合投影、分步揭示和页内原生对象。整份课件共用画布尺寸。
- 流式讲义 Flow：自然排版长页，语义正文随宽度和滚动适配；复杂绝对定位不塞进正文，可用原生对象重建。
- 无限画布 Spatial：世界区域、自由漫游和镜头路径；课堂文字保持易读。
- 原生 Native：稳定图文、公式、形状、媒体及简单点击、切换或播放；独立且常改的内容优先原生。
- 素材：纯视觉图像或已有音视频。核心图示用可用 SVG／HTML 直接呈现；非核心装饰和未配置媒体才留明确占位。
- 互动页：复杂联动、局部实验与连续机制；局部互动先看 Component，整页连续机制可用 Runtime。动态代码须经过产品准入。
- 同一工程可混用三种表面；导入 HTML 可按顶层 section 拆页。
