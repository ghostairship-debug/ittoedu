# 把已确认的页面设计落实为可读画面

在实现页面或修复文字容量、对齐、对比度、裁剪等视觉问题时读取。脚本决定教学内容与风格；本文件帮助落地，不授权删改已确认题干、解释或数据。

## 先读取当前表面与实际内容

从工程获取画布尺寸、稿纸宽度或世界坐标及镜头范围，再安排内容。Slide 的尺寸可能随导入变化；Flow 正文随阅读宽度排版；Spatial 要按实际镜头判断可读性。不要套用外部固定画布、统一边距或字号表。

保留已确认的标题层级、阅读顺序、配色与分区。修改既有页面时先看实际呈现、邻近对象和已有排版规则，确定问题后再改。

## 文字容量与视觉层级

- 用实际字体、字号、字重、行距和容器宽度测量；中文、公式、混合字号和字体替换可能改变换行，字符数估算只能辅助预判。
- 出现溢出时先区分字体/测量错误和真正的内容过量。可以在已确认分区内调整容器、间距或换行；不得默认删减正文或不断缩小字号。必须拆页、改内容或改变重点时返回对应教学阶段。
- 同一语义层级保持一致，标题、解释、数据标注的差异应帮助阅读；投影可读性按真实画面判断，不因笔记本上能辨认就宣称适合教室。
- 使用产品正式文字、公式、表格与图表能力；不要把别的产品的 HTML 文本、LaTeX 字段或固定高度表直接当成 V9 输入。

## 几何关系与素材

- 相同角色的卡片、标签或数据区域使用一致的对齐与间隔；移动或缩放主体时，检查与它关联的标签、箭头和强调标记。
- 看文字与其直接背景的对比，而不只看主题色；换底色时同时检查前景文字、图表系列和状态反馈的可辨认性。
- 图片保持所需比例与关键内容。替换图片后重新检查裁剪、透明边缘、标注对应关系和素材出处，不能只确认资源 ID 已变化。
- 层序按全局 Underlay → Surface → 全局 Overlay；Flow 正文与浮层各自保留语义。不要通过改坐标掩盖错误层序，也不为教师控制器预留正文安全区。

## 修改后的检查

查看改动区域及受其影响的相邻内容；文字、形状旋转和图片裁剪要看对应 Surface 的实际画面。影响静态交付的变化再检查用户要求的导出格式。既有内容保持不变时，不重复重做整课设计。

## 参考来源与适配边界

参考 OpenMAIC [slide-craft](https://github.com/THU-MAIC/OpenMAIC/blob/main/skills/agent-runtime/slide-craft/SKILL.md) 的容量、对比、间距和关联元素检查思路。没有迁入其固定画布、字号/高度表、HTML 字段或数组绘制规则；本文以当前 V9 模型、表面语义和真实测量为准，不依赖 OpenMAIC 服务。
