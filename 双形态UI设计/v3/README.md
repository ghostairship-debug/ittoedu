# 果铃 V3.1 · 设计交互原型

入口：直接打开 `index.html`，或从上层 `打开新版设计.html` 进入。无需安装依赖，也不连接模型或产品服务。

## 查看方式

- 默认：主工作台，对话与内容并排。
- `index.html?view=editor`：原生编辑器，无简洁／专业分档。
- `index.html?view=focus`：内容专注布局。
- `index.html?view=task`：无画布的新对话。
- `index.html?dock=top`：内容在上、对话在下。

## 本轮设计

暖白、墨绿、鼠尾草灰与少量杏橙构成统一视觉。任务、作品与编辑工具在各自工作位置展开；不把人工与 AI 分为两套配色。所有图标取自仓库已安装的 Lucide，`icons.js` 为本地静态图标资源，原型无需联网。

左栏上方资源管理器对应整个工作空间，下方按项目文件夹分组显示各自会话，并允许未归项目的工作空间会话；两部分可以独立收展。项目是工作空间里的真实文件夹，提供优先上下文和默认产出目录，但不限制引用工作空间其他内容。左右区域可收展，布局菜单可把内容放左、右、上或下，分隔线支持拖动与键盘方向键调节。当前原型的左树、中聊天、右内容只是初始默认。

顶部工作空间切换器表示切换独立根目录，不列出内部项目。产品设计合同把工作空间定义为默认完整权限范围，范围外默认只读，额外写入或执行需要授权；本原型没有实现权限隔离，也没有改变当前宿主权限。

`.h5lesson` 在工作台使用场景条和当前场景状态条，在编辑器使用可展开状态的场景树和底部状态条。状态切换显示对应画面变化，并提供新增、重命名和排序入口；工作台与编辑器之间保持当前场景、状态、选区和历史。

## 演示与真实能力边界

这是设计稿，不是产品开发交付。文档文字、课件标题、字号／字重／颜色、场景与状态切换、状态新增／重命名／排序、试运行跳转都是浏览器内演示。内容修改仅在当前页面生命周期内保留；刷新后重置。发送消息展示演示回复，不调用 AI。试运行只为 PPT、PPTX 和 `.h5lesson` 设计，其他内容使用预览、阅读或编辑。

Office 接续、Markdown 专业宿主、组件与交互面板、正式导出只展示入口和说明，不执行宿主操作。Office 宿主可设计为 Microsoft Office、WPS 或其他兼容编辑器；未来果铃原生 Office 编辑器完成后才成为默认宿主。本轮不开发这些宿主。可下载的 Markdown 明确为设计示例。

当前工作空间、项目文件夹、会话和资料均为有限示例数据，未实现真实文件隔离、权限管理或宿主接续。原型没有接入产品代码，也没有改变产品路线、主机权限和任务状态。外部 HTML 编辑器及完整自研 Office 编辑器不属于本轮实现。
