IttoEdu 双形态布局示意

两个形态 · 三种视图 ｜ 编辑器形态 · Agent 形态（工作台布局 / 聚焦布局） ｜ 视口 1600×1000
手动编辑区（蓝） AI 区（青） 结构与导航

编辑器形态 画布为主角

主角：中央画布。编辑器为体、AI 为翼——右栏轨道化，AI 助手是轨道一等入口（面板 320px）。
形态切换在顶栏常驻，切到 Agent 形态时工程、对话与撤销历史连续。

Agent 形态 · 工作台布局 对话为主角

主角：中栏对话。备课阶段——管理课例、引用材料、走四阶段创作流；画布是「看得见的上下文」，只保留轻编辑。
顶栏「工作台｜聚焦」一键切换布局，对话与候选状态保留。

Agent 形态 · 聚焦布局 画布为主角

主角：全屏画布。精修阶段——「生成 → 看效果 → 再改」循环；场景栏与步进器是仅有的常驻导航件，编辑控件全部情境化。
对话收成底部 Dock，有新候选时 Dock 上沿青色呼吸条 + 半浮出候选卡提示。

形态与布局的切换关系

两个形态、三种视图：形态切换是视图切换而非重新打开工程；Agent 形态内「工作台｜聚焦」是同一形态的两种布局偏好。
课例上下文跟随：Agent 形态打开的课例，切回编辑器形态直接落在其课件上。
