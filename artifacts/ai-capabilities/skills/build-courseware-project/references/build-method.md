# 构建入口选择

普通 HTML 新建课件使用 `course.createFromHtml`。软件负责创建目标、资源闭包、内容解析、程序准入与保存，模型提供源文件及用户指定的作品名、输出位置。无需另写构建模块或逐对象执行工程接口。

用户明确要求已有工程修订时使用 `edit-content`；不要用“从 HTML 新建”覆盖教师已经编辑过的工程。修改只影响目标内容和必要的关联布局，保留其他内容。

只有当前任务明确使用外部 Builder V2，且实际执行环境提供该入口时，读取 [外部构建](external-case-build.md)。该入口服务外部案例模块，不是任务入口缺失后的自动替代路线。不要为普通教师创作定位编辑器仓库、生成表示规划、枚举全部工具或运行完整验收矩阵。

交付状态按本次真实结果说明：已经保存的工程、具体程序或资源问题、用户要求但当前未完成的输出。视觉修订参考 [页面设计](page-design.md)，检查范围参考 [验证边界](validation-boundaries.md)。
