# 使用 PPT 原稿与检查导入页面

在已确认脚本使用 PPT 原稿，或用户明确要求检查/修复已导入页面时读取。沿用用户明确的保留、局部修订或改编意图；不能把导入请求自动升级为重新设计整课。

## 原稿与导入结果分别核对

- 原稿提供题干、数据、图示、页序与视觉意图；导入结果提供当前实际可编辑内容，两者不能互相替代为成功证据。
- 当前真实 PPT 入口在顶部“导入 PPT”，支持范围看当前导入界面、能力索引和源码。`.pptx` 的支持不等于旧 `.ppt` 已可直接读取；尚未支持的合并表格、效果或复杂对象不能写成已支持。
- 接受“仅导入可用内容”前查看遗漏/简化提示；技术导入成功不代表原课内容完整。涉及必要题干、图表数据或解释时，明确缺口并按用户意图处理，不用占位物悄悄替代。
- Builder V2 的 `session.tools` 未列出导入工具时，不虚构 `import_pptx` 或直接导入产品内部模块；通过现有产品入口操作，或报告精确能力缺口。保留原件，导入与修订产生当前产品的可编辑结果。

## 检查与修复

先建立原稿与导入页面的对应关系，关注标题、正文、关键图示、表格/图表数据及页序。结合实际画面与导入提示定位缺失文字、乱码、字体替换、遮挡、溢出、失真、旋转或裁剪错误。

小型课件可以逐页看；较长课件先看整体缩略图/页序，详查所有有导入提示的页、题干和数据关键页、明显空白或异常页以及代表性版式。未详查的范围要说明；抽查不能支撑“全课保真”的结论。

修复保留原稿的内容和视觉意图，使用当前工程的稳定目标与正式操作；改完重新查看受影响页面。只在用户要求或已确认脚本规定时增加讲解、练习、互动、旁白或其它内容。必须改变教学内容或呈现方案时，返回编排 Skill 的相应阶段确认。

## 收尾

确认修复内容可编辑、可保存重开，适用的撤销/重做正确；要求交付 HTML 或其它格式时再检查实际结果。分别报告已保留、已修复、仍遗漏/简化的内容，以及未验证范围。相同问题没有新证据时，不靠重复导入覆盖教师已经做的修改。
