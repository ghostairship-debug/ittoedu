# 文件与保存

工作区源文与策划用文件能力，正式工程虚拟路径用工程能力；两者保存状态分别说明。已有文件按当前内容局部修订，新文档直接使用本任务可用的文件创建/写入入口，默认位置以软件回执为准，用户指定目录优先。

工程修改进入正式文档与恢复稿，默认不写盘。用户要求保存或交付已保存文件时使用当前保存入口，依据真实回执的路径和状态交付。内容提交、作业 ready、文件已保存和导出已写盘是不同事实；传输成功不能代替它们。

用户选所需输出与位置，软件负责成果来源、文件身份和保存。目标冲突时保留用户后改，按真实冲突结果选择新名称或处理；不盲目重放结果未知的写操作。图片和计算临时成果按需用成果保存入口，报告只引用真实可打开路径。

交付给出实际文件或当前工程、已完成的内容与具体未完成项。真实预览和互动证据独立于提交/保存回执，不能仅凭源文宣称画面已检查。
