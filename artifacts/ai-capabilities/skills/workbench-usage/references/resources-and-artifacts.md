# 资源与成果

先使用用户材料和当前作品已有资源。示意图可用 SVG，照片查询授权图库，实际生成使用本任务已配置的图像连接；能力未知或未配置时说明原因，不另开收费路径。授权与来源归属随软件资源保存，交付仍说明必要来源和署名。

图库候选用实际取图入口：目标使用本次工程读取的页面或对象路径，图片对象表示原位替换，页面表示插入。替换保留人工位置与图片效果。未指定目标得到本任务资源，可在工程应用入口的 `from` 使用；不自行编造 assets 路径或拼资源编号。图像生成与计算返回的资源也沿用实际回执。

材料图片及当前已授权 MCP 下载/二进制结果返回的 `source` 可直接使用，授权本地文件路径也可作为来源。`media.insert {target,source}` 在已观察页面插入图片、音频或视频；`media.apply {target,source}` 原位替换同类型媒体，保留对象身份、人工 frame、专业效果和未指定字段。可省略插入 frame，由宿主按媒体尺寸放置。页面或整课背景用当前配置入口的 `background.source`。来源原样传给内容入口，软件读取字节、登记资源并提交，不要求先保存临时中转文件或拼资源身份。

组件库检索返回可用条目，用已观察的页或对象路径取用。软件处理依赖和身份；选区提炼只在用户要求时存入库，使用任务绑定范围或明确对象路径。未知信任按实际回执和现有组件库入口处理。

受限计算使用当前计算能力，点名获授权输入与所需输出；不以未授权 shell 或安装依赖替代。等待或查状态只沿用返回的 `job`，不另外选择作业类型；作业 ready 表示成果可用，还未写入用户文件。交付用户选定输出用 `artifact.save {source,destination}`，`source` 直接取创建、状态或等待回执，用户决定目的地；软件处理来源身份及保存，报告引用实际返回路径。无需保存中间缓存，不猜或拼 job/resource/name。未返回成功保存时说明真实状态，结果未知沿原操作查证，不重发作业。

新增工程内容中的相对资源由工程入口解析实际闭包。局部资源问题保留原件和其他可用内容，按诊断修复；不截图静态化。文件交付语义见[文件与保存](files-and-delivery.md)。
