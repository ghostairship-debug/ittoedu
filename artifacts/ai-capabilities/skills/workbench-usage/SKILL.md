# 按需使用工作台

已有目标和编辑入口明确时直接完成任务。这个指南解释软件操作语义，不是每次任务的前置步骤。工具参数、当前配置与权限以本轮提供的工具定义和实际回执为准；这里不维护第二份接口目录或工程 Schema。

- 当前选区或小改：[选择与局部编辑](references/selection-and-editing.md)。
- 页、主题、正文或组件源码：[工程内文件](references/project-files.md)。
- 图片、组件与计算成果：[资源与成果](references/resources-and-artifacts.md)。
- 附件、网页与已有结论：[来源与续读](references/sources-and-continuation.md)。
- 写盘或交付：[文件与保存](references/files-and-delivery.md)。
- 看画面、检查互动：[运行与观察](references/observation.md)。
- 能力或 Skill 入口不明确：[发现与可用性](references/discovery.md)。

内置工具读取本指南用 `skills.read {skill:"workbench-usage",path:"references/所需文件.md"}`。已安装用户/工作区指南用 `skills.list` 返回的完整名称（如 `user/workbench-usage`）；各文件路径相对该指南根。文件环境按链接读取。无需经其他方法的目录或跨根 `../` 路径读取，也无需预加载全部参考。
