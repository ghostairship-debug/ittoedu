# 生成教学初稿

先读取用户材料和约束，已有策划直接复用。默认面向教师演示；自主学习、测验或其他用途按用户要求组织。只补问会改变核心内容且材料无法回答的问题。用户要求直接完成时采用合理假设并在交付说明；要求先看策划或框架时在相应阶段等待，不固定插入两次确认。

先用几个要点想清内容主线、页序、视觉层级和互动作用，简要写入 `01-teaching-plan.md`，随即生成完整 `02-course-frame.html`。这两个文件在同一次创作中产出，不把四个思考维度拆成固定的串行模型回合，也不为落盘计划而等待确认。已有有效策划直接复用。

HTML 顶层 section 对应页面。每页包含可直接呈现的文案、必要图示及有教学作用的展示机制。简化表达但保留成立条件，比较单一因素的影响时说明其他条件相同，条件触发的过程说明成立阈值；让定义、图示、判定和反馈一致，错选解释直接回应所选内容。明确每页要讲清的结论、图中可见的证据及操作后的变化，用于比较的水位、数量或其他图示证据随相关操作实际变化，再用字号、间距、配色和图文关系形成清楚层级；互动用于观察、比较、控制变量、推导或反馈，操作与主要变化相邻可见，并可重复操作。用 SVG／HTML 能表达的核心图示直接做出；只有非核心装饰和未配置媒体可以明确留待补充。关键知识不能只出现在答案反馈或素材说明中；不要用“想象图甲”代替图甲，也不把重复点击文字当作图示推导。

生成前按需读取 Builder 的短 [HTML 合同](../build-courseware-project/references/html-draft-contract.md)，同一次任务已读且未变时直接复用，不读取整套能力索引或 V9 Schema。页面可独立显示和初始化，页内逻辑限定在本页，普通翻页复用正式导航。教师演示不强制过关；自主学习只实现实际需要的条件与反馈。技术标记、正文主推进说明留在备注，不出现在学生画面。禁止远程脚本或未经授权的付费素材调用。

创作时简要检查知识解释、图文层级和核心互动是否真正服务目标，再交给 `build-courseware-project` 导入保存，不把检查变成另一轮固定规划。主图与对应说明按实际视口组织，图示边界完整，背景不盖住标注，图内标注避让。默认不逐页截图、审美评分或后台精修；详细讲稿按需写，额外表示规划不设为必交文件。用户要求局部修订只处理指定范围；明确要求高质量成品或精修时按需观察代表性页面和核心互动，复用已有证据，只修可见问题，必要时再扩大。没有具体未解问题时直接创作，不另读质量方法全文。作品满足要求后直接交付；仅修具体内容、视觉或互动问题，不为无影响的空白整理反复读写。

需要自主学习主路径时参考 [main-progression.md](references/main-progression.md)；教师演示直接使用正式导航。
