# 把整作主线写成观众经历

大型新作的单份策划既说明整作意图，也让已确定场景可以直接创作。它承载内容决定，不是工具操作清单或第二份运行状态。沿用 `<作品名>/01-创作策划.md`；用户已有成熟策划直接承接，不为换格式重写。下面是参考骨架，不是必填表单；短作和局部修改按实际范围简化。

```markdown
# 《作品名》创作策划

## 整作设计
目标与受众：
观众从什么起点进入，结束时获得什么：
主线、场景承接与本次范围：

## 视觉与素材
视觉语言、阅读层级与主要构图：
持续导航的组织、外观、位置及内容范围：
已有材料：
需要主动补足的图片、声音及具体用途：

## 场景：……
作用与前后承接：
初始画面与关键文案：
观众动作 → 材料或状态变化 → 反馈：
完成或离开时的结果与后续条件：
本场景素材与声音的使用：
```

“认识朋友：设计一个互动”还不能直接创作。需要知道初始可见什么、问题用什么真实措辞、什么动作出现哪条信息、回应如何帮助理解，以及它怎样承接后文。静态观察、自由探索和模拟可以有自己的节奏，不强制每个场景都成为问答或设完成门；像素、按钮尺寸和微动画在实际画面中调整。

对关键图像写用途、主体、语义、风格及持续人物特征；对声音写完整台词、角色和出现／重听时机。用户没提供素材时主动补齐，不用“后补配图／音频”替代本次核心内容。软件维护资源身份、引用、播放接线与保存，策划无需内部 ID、资源台账或逐步工具指令。教育内容的成品密度例子见[教学质量](teaching-design-quality.md)。

普通改字、换图、调局部布局或反馈直接读取当前 GLX 目标与必要邻近事实，用正式事务续改；不重做整作策划，不写外部整课 HTML 重导。主线、章节或重要互动关系实质改变时才同步对应策划段落，策划不承担另一份保存义务。
