# 从内容关系到主要画面

主要画面缺乏方向、材料与目标脱节，或真实预览出现拥挤、同质卡片和裁切时读取。先围绕内容关系形成关键体验，再扩展整体。这里提供构图判断，不规定品牌配色、固定网格、每页主图或插图数量；教学例子仅按教育用途采用。

## 背景与节点共同设计

按主题评估颜色、渐变、纹理、真实图片及轻量程序背景。全局底层可按适用范围排除特定页面，前景文字、图形和专业对象仍独立编辑。装饰不抢输入；需要随场景阶段、选择或进度变化时，消费正式事件、共享状态或参数，不直接控制邻页私有DOM。不要复制多个全屏矩形冒充全局背景。

专业文字、表格、图形与图表可以改样式、主题、状态、行为或实例／共享源码，选择服从目标，不必逐档升级。改实现仍让画面消费正式数据，保人工属性和frame；用属性入口实际改一项数据确认响应，再对相关变化保存重开。图标沿已有SVG、图形、图片或局部代码承载，不虚构专用内置icon类型。

## 先找这段内容的视觉关系

从真实材料中选择应该被看见的关系：对象与环境、过程与变化、原文与证据、整体与局部、条件与结果、空间与路径。决定谁是画面焦点，学生先看什么，再看什么，哪些材料需要同时对照。视觉方向应能解释“为什么这样摆”，不能只写“蓝色科技风”或换成任意课名都成立的卡片。

| 内容关系 | 可用的构图思路 |
|---|---|
| 条件与结果 | 让装置、可改条件和读数相邻；比较对象使用共同尺度，图表坐标轴与比较量一致 |
| 原文与证据 | 保留可阅读原文，把证据标记和解释放在对应位置；操作前不先列出待找的答案 |
| 过程与变化 | 用关键状态、时间线或逐步揭示展示变化；保持对象身份与尺度，避免多幅互不对应的装饰图 |
| 结构与路径 | 先给可辨认的整体，再突出局部与路径；线条、标注和节点避让，提供返回整体的入口 |
| 情境与表达 | 让人物、空间、语气和材料构成可判断的情境，选择后变化能被看见；不靠随意分值替代回应 |

这些可以组合，也可以不用。统一字体、颜色含义和图形语言允许不同构图；不要求每页都换风格，也不让每页机械复刻三张卡。

## 素材是教学材料

选择足以承担本段教学任务的素材，不设互联网搜索、生图或SVG的全局优先顺序。按本段需求判断来源、载体和真实可用能力；可以混合使用，不能为证明调用过某工具而添加无关图片。

| 需求 | 可采用的路径与边界 |
|---|---|
| 已提供且适用的材料/指定原作 | 保留复用，尊重用户指定，不为执行固定来源排名重找或重画 |
| 时事热点、具体事件/人物/实物、原始作品和资料 | 认真检索互联网图库及官方/新闻/机构网页原图，核主体、事件、时间和上下文；不限照片，也可搜索插画、既有图示和作品图片。生成图不能冒充现场、原作或事实证据 |
| 故事、绘本、同角色/场景/画风连续图片、定制构图 | 可直接生图/编辑，无需先搜图库；以适用的已有图或首张定稿建立参考，后续持续使用真实角色/场景参考及关键设定。仅重复文本提示不能证明身份一致 |
| 通用配图、概念/情境插画 | 按匹配度、质量、效率、已配置能力选择搜索或生成；现成素材不匹配时可生成，生成也不自动优于合适现成素材 |
| 精确关系、数据、可变参数或互动 | 用原生对象或局部代码，内联SVG/Canvas等按表达选择；无需机械先搜索/生图，不能用漂亮却错误的画面替代准确关系 |

真实图片获取不足时，区分“当前图库没有匹配”“服务不可用”“候选被筛除”和“本次未尝试”，不笼统声称互联网没有。需事实图片但暂不可取得，可保有来源的文字/链接或明确的相关资料图并说明缺口，不能生成假现场遮掩。非纪实故事/情境画面可生成，存在与真实图片混淆的风险时标明其性质。

一致性创作应把实际参考资源传入当前支持的生图/编辑接口，保持关键人物特征、场景关系与画风；合适的稳定角色参考可跨画面持续用，不只依赖前一张动作图。先看少量关键画面是否一致，有偏差局部编辑；不强加角色数据库、复杂评分或大量重试。连接无参考/编辑能力时说明限制，不能假称已验证一致性。

新创作可改/互动图示保留合适代码，不强制变为独立SVG图片；已有优质SVG资产可直接复用。相同绘图换成runtime不自动提高画质，不用粗糙手画示意图默认替代本应搜索或生成的高质量图片。声音/视频按需要听见或观察的过程采用，没有照片不等于缺素材，只有装饰图片也不表示素材充分。

图中标题、刻度、单位、箭头和高亮应与正文同义。标出比较真正改变的部分，让未改变部分保持一致。图示可以简化，但简化不能改变解释所依赖的关系；不能用漂亮却错误的图替代可核对的材料。

## 用编辑器完成分素材构图

需要教师继续改字、数据、位置或动作的内容沿用专业文字、图形、图像、公式、图表、表格和按钮能力。静态材料分别装配；HTML/CSS/SVG可写局部视觉片段，共同源文只保留实际依赖的范围。模拟、游戏或动态联动确实需要脚本时，用独立程序，与外围讲解、图示和导航分开；不要把整个画面烘进一份HTML或一张截图。

Slide适合同屏对照和演示，Flow适合持续阅读，Spatial适合有教学作用的空间关系和镜头叙事。按阅读/观察任务选择，允许混用；不是展示能力越多越好。逐条揭示、作者状态或镜头只在能改善观察节奏时采用，不强制所有页动画化。

## 在真实画面上判断

先看最能体现学习难点的片段，再按需要局部修订：主要材料是否可辨，正文是否适合实际演示尺寸，标注是否完整，视线能否从操作找到结果，揭示/替代状态是否仍能容纳内容。原生文字与局部程序属于同一主要画面，程序中的选项、图标注和反馈也按实际课堂显示尺寸设计，不能只放大外围标题而沿用网页小字。长反馈与选择区争位时，按学习顺序调整该局部的空间、精简重复提示或分步呈现，保留当前判断所需的条件与证据；合理滚动可以承载长阅读，但加滚动或缩字号本身不证明主要操作与反馈已可读。学生需要的较长解释可用合适的Flow内容承载；教师组织说明留现有策划，不自动另生成讲稿或备注。

检查实际绘制范围，包括SVG文本、坐标轴、图例、控件和变化后的最长反馈。发现裁切时调整该素材的尺寸、布局或文本，而不是缩小整页或重排人工位置。导航按本课实际选用形态检查；正常讲授不应反复拖走或收展浮层才能看清主要内容，不为完整控制台强设全课安全区，也不开发自动避让来替代适当布局。

局部有效观察可以复用；没有变化不重复截全课。视觉判断与提交、保存、互动事实分别说明，代码存在或软件装配成功不表示画面已经看过。
