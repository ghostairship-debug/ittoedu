# 让选择产生当前后果与可解释反馈

用于需要操控、探索、取证、表达或决策的片段。先确定观众改变什么、相关材料或任务怎样响应、结果为何有意义，再在正式关键片段落实动作和使用路径。按内容选择揭示、选择、连续变量、空间探索或其他已有能力，文案、数据和反馈消费当前事实。静态展示与阅读也可承担主要目标；以下教学方法仅在教育用途采用。

## 先确定互动揭示什么

用一段连贯描述说明：观众作出什么选择，哪些条件保持不变，当前材料、任务状态或后续解释有什么变化，以及如何理解这个后果。变量名称、单位和比较对象来自实际内容；按钮数量、滑块存在或分数变化本身不构成体验目标。

研究面积可以保持一边不变，改变另一边，对照图形与面积来解释关系；认识面积定义也可直接用图示与讲解。决策体验可以让同一条件下的两种选择揭示取舍；环境与选择同时变化时，分别解释其影响，不把有利条件当成策略普遍更好。

## 按任务选择操作

| 学习需要（教育用途） | 可考虑的呈现与操作 |
|---|---|
| 理解变量关系 | 先预测，再控制变量、观察结果、比较并解释 |
| 阅读与材料取证 | 标记或选择证据，与推断、冲突材料或另一表征联动，说明支持范围 |
| 理解结构或流程 | 展开局部、追踪路径、对照整体；始终能返回整体 |
| 学会方法 | 看示范、完成有支持的步骤，再独立应用 |
| 作出分类或排序 | 说明判断依据、操作对象与反馈；分类去向和真实顺序变化分开描述 |
| 检验决策或空间认识 | 用有意义的规则决策，或从不同视角观察；结果支持解释 |
| 表达与创作 | 修改材料后看实际回应或关系变化，再解释自己的选择 |

这些是可选方法。同一机制可以连续使用，讲解、示范与总结也可以承担主要任务，不为形式多样强制换操作。区分系统示范与观众亲手操作；有完成条件时，以实际操作、解释或结果为依据，不以点击次数冒充完成。

## 在正式片段兑现选择

先落实初始材料、可操作对象、变化范围和当前后果，让操作与受影响材料容易对照。图形、数值、标注、任务状态、记录及解释消费同一实际状态；记录保存这次操作的数据。比较与复盘涉及观众选择时，使用这些真实结果；固定预置可作明确例证，不能替代或冒称观众的记录。

反馈回应这次选择及其依据：哪个条件造成变化，哪些目标实际实现或未实现，为什么，以及可以尝试什么。未供能的请求、未发生的动作或未知结果不能报成收益。图形变化、实际读数或角色回应也可以构成反馈，不强制每次弹出对错；开放表达不伪造情绪值、语义分数或自动评分。

安排信息出现时机：初始画面保留判断所需材料，等待观众观察或发现的信息在相应动作后出现；反馈解释当前后果，总结把已经获得的局部信息连起来。教育内容可采用 Question → Action → Feedback → Conclusion，但这只是适用的表达方法，不强制每页四步，不把静态观察、自由探索或模拟改成问答。关键知识仍须有真实教学路径，不能只藏在答错反馈中。

按真实依赖确定内容边界。共享计算、控制或必要排版关系的实验可保一个局部程序，外围独立标题、说明、图示、配图和导航分别承载，不为方便统一样式并入整页脚本。普通源文沿现入口装配，由软件处理能保真的拆分；复杂表达不为可抽取而降级，程序内行为也不要求逐项添加人工面板。

需要跨位置回看预测、数据或作品时，确定哪些当前事实要延续，使用已提供的共享状态/组件能力；不要访问另页DOM或假设局部变量自动共用。继续与返回到达实际选择及后果，复位按约定重置。单片段能完成目标时不强制跨页或多时段。局部实验确需暂停时在自己的代码内实现，不建设平台统一暂停/寻帧或任意运行状态编辑后恢复。

在正式关键片段操作一次有意义的选择，核对当前结果和解释；采用比较、返回或复位时检查其实际语义。已有有效未变证据就停止同属性自检，新的承载或导出只补其特定消费差异。发现真实问题只修受影响内容，不以重复截图、全分支矩阵或追加确认代替设计判断。互动删除后若目标和证据没有变化，重新判断它是否值得保留。推进及现场控制见[推进与使用路径](main-progression.md)。
