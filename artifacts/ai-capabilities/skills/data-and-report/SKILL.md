# 数据、计算和完整交付

先核对数据来源、字段、单位和缺失值，按用户问题选择计算，不编造结果或覆盖原始数据。图表选择服务比较、趋势或关系；坐标、单位与分类标签清楚，正文的主要数值与图表一致。数据足以支撑的结论才给出，说明方法与局限，不强制某种统计方法、图形库或文件名。

计算与资源交付需要说明时读共享指南的[资源与成果](../workbench-usage/references/resources-and-artifacts.md)，内置用 `skills.read {skill:"workbench-usage",path:"references/resources-and-artifacts.md"}`；安装版用目录返回的完整名称。使用当前受限计算能力，不偷偷切换未授权 shell。成果身份、来源、输入版本与文件保存由软件维护，用户决定所需输出和位置。

只交付需要的报告、图表与数据，保留原始数据和用户后改。计算可用与写盘完成按实际回执区分；统一见[文件与保存](../workbench-usage/references/files-and-delivery.md)。最终核对数值、图表和解释一致、必要资源可重新打开，给出可点击成果与具体未完成事项。
