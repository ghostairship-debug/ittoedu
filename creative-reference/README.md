## 查找、采用和修改

- 需要方法或案例时，使用现有 `file.search` / `file.grep` 查本目录及链接中的资料，再用 `file.read` 读取必要内容。这是仓库内参考文件，不是新的 Skill 注册表。
- 需要可执行组件时，沿现有 `asset.search` 查询，例如“连续阶段背景”或“连续变量联动”；身份和版本以实际返回为准。确认适合后使用 `asset.use`。未安装的组件按其说明，通过现有 `asset.import` 导入源目录中的归档。
- 参数、正文和源码修改沿当前工程的 `project.list`、`project.read` / `project.apply` 及既有对象操作完成。目标路径和身份由软件返回；不要从案例复制实例 ID，也不要改完外部整作后覆盖正在共编的工程。
- 案例只作设计参考也可以。采用成本高于直接实现，或者主题、互动和编辑需求不同，就记录拒用原因并选择更简单的做法。

Markdown 链接相对本文件；用文件工具读取时，先将它们解析为已授权工作区内的实际路径。只在包含该仓库的工作区中读取；没有本地参考目录的独立安装仍使用已有内置指南与资产库，不宣称这些资料已经打包或自动随应用分发。
