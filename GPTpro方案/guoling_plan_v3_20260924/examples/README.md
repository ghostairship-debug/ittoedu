# 样例说明与手动验收

这是一组原创6分钟教学片段的管线夹具：两份MD加两页静态HTML框架。HTML含真实文案与三个槽（互动、可选图片、精确图解），没有生成最终素材，也没有内置编辑器或模拟自动保存。

用浏览器直接打开可查看设计；其中的data属性由未来果铃宿主识别。本文件不要求全局安装字体或任何网络资源。示例用固定1280×720测试，浏览器窄屏需缩放；正式工作台应提供适合窗口的画布缩放。

## 静态映射/HTML编辑实现时的选测流程

1. 在宿主中打开 `layout-shell.html`，将第一页标题改为“缺的这一块，面积是多少？”，移动并缩放互动槽。
2. 等实际文件自动保存，关闭并重开。确认修改保留，MD文件内容/hash未变。
3. 删除可选图片槽，保存。槽提取应只返回 `area-demo` 与 `equivalence-diagram`。
4. 下游使用新标题、新尺寸和现存槽，MD只补充必要教学/互动说明。
5. 生成并装配后继续手改原生工程，再尝试重新生成；不得默默覆盖已修改原生工程或反向更新MD/HTML。

样例不是已实现功能的演示。自动保存、文字编辑、拖动、尺寸调整、素材生产、原生装配都需要宿主实施与实测。本包只提供它们的约定、输入样例和验收。

## V3.3中的用途

已补显式text/shape/slot角色和两个MD片段标识，并去掉首轮尚未约定的文字字距。它仍是两页静态输入，不是成品或产品实现。它仅验证简单静态区域映射与草稿轻编辑，不作为所有内容必须被简化的标准。2.0优先验证真实听力HTML整体导入、Runtime图文轻编辑及Flow长网页；本夹具仅在实现对应静态功能时选用，机械拆原生不再是前置。

机械检查应忽略槽的虚线/待生成说明，保留真实正文与色块；HTML源与MD片段只单向关联背景。未提供新宿主时不能在普通浏览器中测试自动保存、拖动或正式导入。本轮未重新执行此样例的可视排版验收。

V3.3未改两份样例MD和HTML。已有data属性是历史静态转换夹具的一部分，不意味着新框架HTML设计要提前读编辑器能力；新流程按03，框架完成后才由后置策略/程序处理实现标识。
