# 历史测试模板与选测边界

本目录为既有基准模板，不是当前Codex任务/验收登记。V3.3保留全部JSON字节、35个历史ID及原测量结果，不新增ID、不填通过状态；原定义用于对应静态/历史范围，不覆盖本轮全部新能力。

Runtime/HTML/Flow新增完成标准写在02和14，由后续实现根据实际改动选择已有测试或补最小检查；本轮不另建台账。旧模板内要求显式标识的静态映射规则，只适用于那个转换子集，不约束自动图文发现与整体Runtime导入。

开发期优先用原HTML与机械导入结果、少量关键状态和一次修改保存链；确需归因时才补当前生成结果形成F-HTML/F-CURRENT/F-PRESERVE。不是每次用户生成都跑三组，更不叠加旧教学A/B/C成为六组必测。

Phaser/Three支持类型、长网页Flow与新建生产链按02的代表路径验证，可以合并样例，不展开引擎×Surface×状态全组合。保存/撤销/权限既有证据可复用，改动该边界才复验。

时间/费用取已有日志，没有的数据保留null；不为填表造埋点、逐帧录制、像素评分或审美Agent。Office候选/测量模板原样保留，与这轮2.0创作增量不是同一个完成条件。
