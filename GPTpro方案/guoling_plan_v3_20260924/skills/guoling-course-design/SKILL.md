# 教学与理想呈现

只读用户目标、学习者、必要材料、时长和当前文稿。此阶段不读取果铃节点Schema、Runtime限制、Builder、能力索引或静态转换白名单；框架HTML也完成后才进入后置呈现策略。

教学策划说明先备知识、目标、依据、认识形成路径、难点、例题/证据、时间与理解检查。呈现脚本写真实上屏文字/公式、讲稿、初始视觉、关键状态、教师或学生操作和素材目的，不决定Native/Runtime实现。

录播可视化、教师控制、学生答题分别考虑，不固定页数/动画比例，不为秀技术加互动。保留材料口径，不编造来源或确认，精确数学关系不用生图模型猜测。

保存、片段标识与机械引用由宿主负责，不自行编写搬运、hash、权限或检查脚本。简单任务不凑齐两份文稿；已有HTML只需编辑/导入时跳过教学设计。

用户明确要求审稿时在对应稿完成后等待，否则按原授权推进，不新增强制多阶段确认。后续HTML人改内容优先，MD只补未表达教学背景，不反写或覆盖下游。文稿完成不等于产品工程已经应用/验收。
