# 带槽HTML：静态原生映射子集

**V3.3｜可选后续原生映射参考，不是2.0整体Runtime导入的前置。框架HTML完成前不加载本文件；不是设计模型的表达限制。** 本文仅约束“静态区域→原生节点”的窄路径，不是全部创作/模块的CSS白名单。已有完整HTML与复杂交互区域优先保留实现，使用现有Runtime/Component实际支持的能力；不为符合本子集而简化作品。

## 页面、身份与可编辑范围

首轮 `.gl-page` 使用固定 1280×720 CSS 像素，页面 `position:relative`；这是演示页试点，不限制既有 Flow/Spatial。页面宽高与能力由宿主校验，画布缩放不写进对象。

仅本静态映射路径的页面和被装配对象需要唯一 `data-gl-id`。页面直属对象显式标记 `data-gl-role="text|shape|slot"`；slot 的 kind 决定素材用途。首轮不递归编译任意嵌套容器。普通布局包装/草稿说明要明确不进入最终作品，不能无声明地漏掉正文。

`data-gl-edit="text move resize"` 只声明操作子集；`data-gl-locked="true"` 表示显式锁定。宿主决定实际能力和提交权限，属性不授予文件访问。首次无脚本、无内容编辑器时这些属性不会自行生效。

## 支持矩阵

| 对象/属性 | 首轮规则 | 超出时 |
|---|---|---|
| text | 页面直属纯文本或 br；固定外框，字号、字重、颜色、对齐、行高、内边距、明确字体 | 富文本跨度/复杂排版报 unsupported，不静默打平 |
| shape | 简单纯色色块/矩形；位置、大小、填充及已经验证的基础边框 | 渐变、阴影、滤镜、复杂路径暂不承诺 |
| slot:image/background | 已准备图片资源填槽；明确 contain/cover，背景与内容作用域不同 | 缺资源或无法解释 fit 报错，不凭空生成 |
| slot:diagram | 已验证 SVG 图片或原生图形模板；SVG 作为图片时明确内部非原生深编 | 不把整页或公式正文烘焙进图 |
| slot:interactive | 引用实际组件成果，按外框装配并走已有真实准入 | 不把占位文字/静态后备当互动完成 |
| slot:video | 保留语汇；后续存在实际媒体/生成路径后再启用 | 首轮可报告 unsupported，不强制实现 |
| 公式 | Unicode 简单式可按原样文字保留；复杂式须明确源码并走已支持公式路径 | 不从渲染 DOM 逆猜 LaTeX，不毁掉现有原生公式能力 |
| 几何与层级 | absolute 的 left/top/width/height 为有限 px；页面直属 DOM 顺序为层顺序；文字允许内部换行 | transform、百分比布局、calc、Flex/Grid、伪元素、动画、混合层叠先不编译 |

样式可用静态class，提取按实际规则/计算值。字体替代与换行在首次接入或相关改动时核对；不每次保存重测字体。支持集不足时保留完整区域或明确宿主限制，不强迫把有价值的设计改简单，不偷偷截图。表中“不编译”不等于现有模块不能渲染。

页面背景可以成为原生场景背景；页面用于预览的外边距/边框和槽的虚线、说明、待生成字样不进入作品。slot 内部文字仅作占位说明，不再提取为独立正文。

## 槽与背景定位

```html
<section class="gl-page" data-gl-id="page-1" data-gl-fragment="gap">
  <div data-gl-id="area-demo" data-gl-role="slot"
       data-gl-slot="area-demo" data-gl-kind="interactive"
       data-gl-brief="教师补齐单位缺角，显示边长；支持重播；x>0"
       data-gl-edit="move resize"
       style="position:absolute;left:590px;top:92px;width:610px;height:430px">
    <p>互动组件待生成</p>
  </div>
</section>
```

kind 仅使用 image / diagram / video / interactive / background；“词表中有”不等于生产/装配能力已经实现。`data-gl-slot` 与本元素 id 一致，避免两套身份。需要扩类型时先有真实 consumer。

`data-gl-required="false"` 表示可选素材；默认关键槽只约束仍存在的槽，不允许装配时静默丢失。用户明确删除槽后不再生产或从旧 MD 恢复，即使之前标为关键。

页面可用 `data-gl-fragment="gap"` 对应呈现 MD 的 `<!-- gl-fragment: gap -->`，仅提取该片段背景；不映射行号、不双向同步。标识失效但任务已提供明确局部背景时可继续；否则补清必要内容，不盲配或为补标识重跑全课。两份 MD 仍是可读文稿，不要求另建大型 JSON。

## 保存、提取与装配

当前 HTML 是布局/文字/现存槽的正式来源；DOM 是编辑投影，来源版本和正式写入归宿主。手势/完整输入确认后自动保存，IME 未结束不冻结半成品。选框、手柄、临时 contenteditable、宿主桥和临时脚本不能进入文件。

引用资源使用授权的可搬迁路径或现有受控协议；Blob URL 不作持久引用。在本静态映射路径，脚本、on*属性、未授权远程依赖、运行期DOM重建不进入直接提取范围。完整模块保留业务脚本，仍走现有安全隔离/准入；不能把其脚本当编辑装饰清除，也不因此给内容文件权限。

槽清单、对象坐标表、snapshot、fills 是程序派生的任务数据，不是教师维护的第二份源。装配必须使用当前受支持模型；data 属性不能绕过严格 V9 合同。


## 完整模块与自动轻编辑

已有完整HTML不必补齐本页标识，也不创建全部DOM到原生的映射表。组件沿现有模型保留源码/数据与资源，宿主自动发现常见图文，优先连到已有正式内容键；必要窄覆盖仍由同一工程会话持有。动态目标身份与Flow页面承载见14，不要求作者逐项补expose。

模块内未开放字段仍保留，不能为方便映射删译文、人物关系或播放状态。关键内容/交互对照在开发期代表案例中做，不能将本约定变成逐生成审美审核、全量hash或通用可视化编译标准。
