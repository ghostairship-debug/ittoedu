# 关键运行链路与状态约定

## 普通直接编辑

1. 用户原话、显式附件和当前可见上下文进入消息；选区卡明确请求局部修改时附加局部grant。
2. 宿主生成任务身份、DocId与短目标句柄；模型无需手填内部revision/owner。
3. 模型在同一执行回合调用领域工具。网关解码并校验权限、句柄和幂等键。
4. 文档Kernel在自己的串行队列中重验读写前提，执行领域操作，写恢复记录，提交一次内容与资源History。
5. 视图收到doc.changed，更新对应对象；工具结果返回同一个模型回合。
6. 模型决定继续还是结束。宿主不要求再写candidate文件，不因最后结果尚未写入显示日志而重做内容操作。

`applied`只表示内核正式内容变化，`saved`表示文件持久化成功；UI不能用一个状态混淆两者。句柄不是永久万能授权，工作空间/文档/运行生命周期变化时失效。

## 正文内容流

宿主为明确文本范围建立EditDraft，绑定DocId、基线、范围和运行ID。真实内容分片按sequence更新临时投影；重复分片不重复添加，缺序时请求快照或显示重连，不能猜补内容。

原文保留为恢复基线，生成中的文本不通过每token正式History写入。完成时处理最终快照与已收分片，校验目标和资源，提交一个撤销组。失败/停止取消未完成草稿，之前已完成的操作保留。

正文/源文切换都展示同一正式状态与同一编辑草稿的对应视图，流式生成不能因为视图卸载而丢失。复杂对象输出尚不完整时只能做临时占位/投影，不能当作已完成正式对象。

## 用户同时编辑

2.0同文档同一目标只允许一个活动AI编辑草稿；用户想改该目标时可停止当前生成后编辑。目标以外的人工操作可以继续，流式投影的位置由文档事务映射更新。

修改前后的读集合及锚点不再成立时返回明确冲突，保留用户当前内容。不把“用户切页面/点输入框”当作内容冲突，也不通过换用最新revision强行接收。

## 停止与迟到结果

停止先设置run失效屏障，再请求后端取消；网关拒绝屏障之后的新增操作。已经入正式提交序列的操作按实际结果结算；UI展示已完成部分，不回滚无关人工内容。迟到的模型输出、工具结果和恢复连接不能复活任务。

操作响应丢失时通过operationId查询实际结果。已完成则返回原回执，不再次执行；未提交才按原grant与目标检查后处理。新用户请求即使文本相同也不是原操作重放。

## 文件移动与重命名

FileService暂停目标绑定上的保存队列，处理dirty草稿与冲突，执行安全移动，更新FileBinding和相关资源相对引用，再恢复保存并广播绑定变化。DocId、会话身份与History保持稳定。失败时原绑定/原内容保留，UI显示明确错误。

另存为保留当前会话对象但更换其文件绑定；“另存副本/复制文件”创建独立文件和DocId。两者不能用同一个状态转换偷偷实现。

## 工程导入与可执行内容

外部整工程先在受控范围解析资源和结构；可执行内容在隔离宿主完成必要检查。通过后仍以正式文档操作提交并记录History。用户在软件内看到结果，不去临时目录手动阅读候选。

该链路不能成为所有文字/样式编辑的统一前置。模型需要观察可调用观察工具，应用不固定追加语义评审或审美打分。


## API、套餐与模型角色

发送时冻结 ExecutionProfile：对话/规划、视觉理解、图像的连接与模型，以及实际认证/计费来源。Token Plan 是 API 的一种计费配置，不与 OAuth 绑定。单任务可组合角色，不因图片需要自动切换未授权供应商。额度错误保持原配置，用户明确设置的回退才可使用。

## 外部 MCP 交接

内置 run 停止并结算 → 生成要求/目标/已提交/剩余工作交接包 → 外部客户端接入同一 Server 并取得新 grant → 重新观察 → 调用同源工具 → 回执与内容区同步。工具票据重试只返回真实原结果；独立新意图不按文本去重。果铃撤权只阻断果铃调用，不承诺停止外部循环/磁盘工具。

## 图像与构建长任务

在同一执行器注册媒体/构建 job。图像生成/编辑完成后校验资源并导入；构建先在可写 scratch 准备与真实检查，再正式导入。未知请求状态先查询或记录未知，不能自动重发收费任务。取消后晚到结果不自动应用，已提交内容与实际费用单列。
