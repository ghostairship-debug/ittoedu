## 固定决定

统一自建执行器覆盖直接编辑、素材与受控构建；API/Token Plan 为主，OAuth 可选；低成本 API 生产与高能力对照分别验收。外部 AI/CLI 通过统一 MCP 使用果铃，不深度嵌入三套原生运行时。

DocumentSession 为文档内容的唯一正式 writer；人工、内置 AI、MCP 共享 ToolCatalog/Gateway。非文档能力使用各自服务与结果语义，后续扩展见 [L03](../long_term/L03.md)。删除旧用户迁移与双内核切换；保留代码职责迁移、恢复、保存和构建 staging。普通编辑不再经过候选文件。
