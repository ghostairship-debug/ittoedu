## 证据层级

合同与单元测试验证核心不变量；事件回放验证适配和显示；Electron/Windows测试验证界面与系统集成；真实模型测试验证上游实际接通；独立用户测试验证产品路径。任何一层不能代替其他层。

`passed`只能由实际断言与结果产生。`not_run`、`blocked`、`skipped`保留原状态，不汇总为绿色；如果关键路径环境无法测试，解决环境或声明内部测试构建，不能宣布正式发布。

## 外部可用边界

用户通过 API 地址、Key 和模型配置进入生产，包括实际允许的 Token Plan。OAuth 是可选登录；外部 MCP 注册为独立入口。当前可运行产品构建须在无 CLI、无 GPT 订阅下完成主流程；非开发机器上的正式包首次使用留待发行准备。每条声明的连接/客户端均有对应证据，不支持项如实呈现。

不得偷偷替换用户的供应商、模型、档位或计费来源；不把订阅登录权益视为通用API额度。所有运行时、依赖与分发授权上线前按实际条款核查，评审结果进发布记录。

## 构建与恢复

当前开发保留应用/data schema 版本及 2.0 自身恢复记录，并验证本地构建中的恢复行为。发行准备再固定分发包源码和构建环境。不做 1.x 聊天/缓存升级迁移或双内核回退门；开发基线与样本副本保留。后续真实数据版本升级另定兼容合同，不能用旧程序覆盖新数据。

卸载默认不删除用户真实工作目录。临时素材与应用日志清理不触及仍被文档、撤销记录或未发送消息引用的Blob。诊断导出经用户发起并脱敏；不自动上传原文与图片。

## 发布场景

### REL-T05｜崩溃与磁盘失败

**环境／前置：** 多文件含dirty/附件和活动操作

**操作：** 复用已通过的故障注入与恢复证据；草稿、提交、保存三个阶段中尚未覆盖的，补注入失败并重启

**验收：** 数据可恢复；记录缺失不重放已提交操作，未保存状态准确

**验证层：** integration；范围：`2.0`；当前状态：`passed`。

**证据：** `evidence/B07_2026_09_23_INTEGRATION.md`、`evidence/B08_2026_09_24_INTEGRATION.md`

### REL-T06｜权限与非可信内容

**环境／前置：** 恶意附件/链接/工具参数、外部路径、过期句柄

**操作：** 复用已通过的越权、撤权与非可信内容证据；跨根/跨文档/停止后写入及非可信 HTML 执行中尚未覆盖的，补测

**验收：** 按权限档位检验边界：只读零写入，修改前询问须批准，工作空间档写外部路径须批准，完全访问仍经正式编辑通道；停止后写入为零；非可信 HTML 不执行；凭据与敏感日志不泄露

**验证层：** security；范围：`2.0`；当前状态：`passed`。
