# M16｜Flow 混合画布、自由原生图层与页面 Runtime

**阶段：中期产品体验 · 2.0 必须完成**  
**实施依赖：** M15、M05、M13

## 完成定义

Flow 保留现有 SharedDocumentEditor / Markdown 连续正文，同时恢复最初“流式便利 + 自由画布能力”的关键部分。Surface 主要决定空间组织方式，不再意味着 Flow 只能使用文档块。

## 产品语义

正文新增文字继续走 paragraph/heading 等 Document 操作；产品和 AI 原来的“插入文字”改为插入“文本框”，即 paper-space Native Text。Native 文字、图片、形状与组件可以作为 paper 自由图层；浮动能力沿用现有组件机制，不另建浮动 Runtime。旧 DocumentBlock 不删除，历史工程继续读取。

自由图层默认**跟随所属段落**移动（Word 的“随文字移动”）：在其上方增删段落时图层随段落位移并保持层级。图层也可选**固定在纸面**，位置不随正文变化，并可置于正文下方，用作背景或水印（2026-09-25 Owner 决定）。选中后使用 M21 的统一快捷条与 M15 的元素 AI 卡，不另做一套讲义编辑界面。

**挂靠规则（2026-09-26 Owner 决定，收敛方案 §7C）：** 自由图层默认挂到其顶边所在段落，拖动时显示挂靠位置；挂靠段落被删除时改挂前一段；横向位置按纸面宽度比例；正文不绕排自由图层，需要绕排时使用正文图片的环绕排版。V9 与 Published 新增可选的“挂靠段落”字段，缺省表示固定纸面。

**正文编辑：** 正文保留 Markdown 模型，支持输入即转换（`# `、`- `、`1. `、`> `、代码围栏、`---`、`$$`），空行常驻“+”并支持“/”菜单；光标所在段落显示手柄“⋮⋮”，菜单为转换为、上方/下方插入、复制、删除、上移、下移与 AI 修改，并可拖动排序。选中文字使用统一快捷条（粗体、斜体、下划线、颜色、高亮、链接、公式、AI；删除线、上下标、行内代码、着重号、字号、字体与清除格式收进“⋯”），取消右上角“正文格式”面板，源文模式放进“⋯”。

**插入与媒体：** 插入菜单分“插入到正文”（标题、列表、表格、公式、分隔线、提示框、折叠节、图片、视频、音频、组件）与“放到纸面上”（文本框、图片、形状、组件）。图片默认插入正文，可“改为浮动”并可改回；正文媒体快捷条提供替换、裁剪、排版（正文宽、宽幅、通栏、左环绕、右环绕、说明文字、改为浮动）与 AI 修改；表格操作在快捷条与右键中。工作台插入菜单不提供按屏幕定位的浮层。实施分四步（正文编辑、插入与媒体、挂靠与字段、页面 Runtime），HTML 页面插入归 M17。

Flow 页面 Runtime 作为正文中的整块区域，使用现有 surface-runtime 路线承载长 DOM/HTML；编辑态直接挂载真实 Runtime，而非仅显示标签或 fallback。长内容以实际高度/ResizeObserver 等窄机制更新占位，不建立第二套布局引擎。

## 停止条件

不把 Flow Schema 重构成 Slide 子类，不追求 2.0 内全部 Slide interaction parity；复杂联动优先由 Runtime 承担，先恢复自由图层与页面 Runtime 的实际可用性。
