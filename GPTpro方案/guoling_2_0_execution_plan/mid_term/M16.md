# M16｜Flow 混合画布、自由原生图层与页面 Runtime

**阶段：中期产品体验 · 2.0 必须完成**  
**实施依赖：** M15、M05、M13

## 完成定义

Flow 保留现有 SharedDocumentEditor / Markdown 连续正文，同时恢复最初“流式便利 + 自由画布能力”的关键部分。Surface 主要决定空间组织方式，不再意味着 Flow 只能使用文档块。

## 产品语义

正文新增文字继续走 paragraph/heading 等 Document 操作；产品和 AI 的“插入文字”改为创建 paper-space Native Text。Native Image/Shape/Component/Runtime 同样可以作为 paper 自由图层随正文滚动。旧 DocumentBlock 不删除，历史工程继续读取。

Flow 页面 Runtime 使用现有 surface-runtime 路线承载长 DOM/HTML 区域；编辑态直接挂载真实 Runtime，而非仅显示标签或 fallback。长内容以实际高度/ResizeObserver 等窄机制更新占位，不建立第二套布局引擎。

## 停止条件

不把 Flow Schema 重构成 Slide 子类，不追求 2.0 内全部 Slide interaction parity；复杂联动优先由 Runtime 承担，先恢复自由图层与页面 Runtime 的实际可用性。

## 验收用例

### M16-T01｜Flow 正文与自由文本语义分离

**环境／前置：** Flow 已使用 SharedDocumentEditor/Markdown 正文

**操作：** 在正文光标处新增段落，再使用“插入文字”入口新增独立文字

**验收：** 正文新增仍是 Document paragraph/heading；“插入文字”创建 paper-space Native Text，可独立移动/缩放，不再创建旧式独立正文文字块

**验证层：** electron；范围：`2.0`；当前状态：`not_run`。

### M16-T02｜Flow paper 自由原生图层

**环境／前置：** Flow 页面有足够纵向内容

**操作：** 加入 Native Text、Image、Shape，移动到不同纵向位置并滚动、保存重开

**验收：** 自由图层随 paper 滚动并保持位置/层级；Markdown 正文不被拆成图层，已有文档编辑能力不退化

**验证层：** electron；范围：`2.0`；当前状态：`not_run`。

### M16-T03｜Flow 页面 Runtime 长内容承载

**环境／前置：** 一个高度明显超过初始视口的 DOM 页面 Runtime

**操作：** 在 Flow 编辑态挂载 Runtime，改变 Runtime 内容高度，叠加一个 Native Text，再试运行

**验收：** Runtime 可作为 paper 内容区域显示并按真实/更新后的内容高度占位；原生图层可覆盖或标注，编辑态与试运行不使用两份不同内容

**验证层：** integration；范围：`2.0`；当前状态：`not_run`。

### M16-T04｜Flow 混合内容保存与导出保全

**环境／前置：** 同页同时包含 Document 正文、paper Native、Runtime

**操作：** 分别修改三类内容，撤销一次，保存重开并执行当前已支持导出/预览

**验收：** 三类内容各自保持正式来源，不互相转换或覆盖；原有 Flow 正文、资源、试运行与导出能力无明显回归

**验证层：** export；范围：`2.0`；当前状态：`not_run`。
