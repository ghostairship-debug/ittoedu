# M19｜Slide 有限画布尺寸参数化

**阶段：中期产品体验 · 2.0 必须完成**  
**实施依赖：** M17

## 完成定义

Slide 从“固定 1280×720 演示页”收敛为“有限二维自由画布”。1280×720 继续作为旧工程和默认模板，不再是 schema、坐标和 Runtime authoring 的硬编码唯一尺寸。

## 实现范围

集中参数化 Course Project canvas、stage viewport transform、hit test、选择框、拖拽缩放、Runtime authoring bounds、试运行与受支持导出所依赖的逻辑尺寸。至少验证标准横屏与一种非 16:9 有限尺寸。

不借此建立完整纸张/打印系统，不把 Flow 改成长 Slide，也不把 Spatial 有限化。三种 Surface 仍分别代表有限自由布局、连续流式布局和无限世界+镜头。

### M19-T01｜Slide 有限画布不再写死 1280×720

**环境／前置：** 旧 1280×720 工程与一个新建非16:9有限画布

**操作：** 打开旧工程，新建另一尺寸，放置图文并保存重开

**验收：** 旧工程无迁移损失并保持1280×720；新工程持久化实际 width/height，节点坐标以当前画布为准

**验证层：** integration；范围：`2.0`；当前状态：`not_run`。

### M19-T02｜坐标、选择与 Runtime 目标跟随当前画布尺寸

**环境／前置：** 至少横屏和竖屏/长页两种有限画布，含 Native 与 Runtime 图文目标

**操作：** 缩放适配窗口、点击选择、拖动缩放并编辑 Runtime 文字

**验收：** 命中、选择框、拖动与 Runtime target bounds 使用当前画布尺寸，不发生按1280×720错误归一化

**验证层：** electron；范围：`2.0`；当前状态：`not_run`。

### M19-T03｜非标准有限画布保存预览与导出

**环境／前置：** 一份非1280×720有限 Slide，含 Native 与 Runtime

**操作：** 保存重开、当前位置试运行并执行受支持导出

**验收：** 尺寸与构图保持；不因为支持自定义 Slide 尺寸改变 Flow 的连续文档语义或 Spatial 的无限世界语义

**验证层：** export；范围：`2.0`；当前状态：`not_run`。
