# M19｜有限画布参数化与三视图统一

**阶段：中期产品体验 · 2.0 必须完成**  
**实施依赖：** M14

## 完成定义

Slide 从“固定 1280×720 演示页”收敛为“有限二维自由画布”。1280×720 继续作为旧工程和默认模板，不再是 schema、坐标和 Runtime authoring 的硬编码唯一尺寸。2026-09-26 起本任务同时负责编辑、试运行、整课预览与导出四处看到同一页面。

## 实现范围

集中参数化 Course Project canvas、stage viewport transform、hit test、选择框、拖拽缩放、Runtime authoring bounds、试运行与受支持导出所依赖的逻辑尺寸。至少验证标准横屏与一种非 16:9 有限尺寸。

不借此建立完整纸张/打印系统，不把 Flow 改成长 Slide，也不把 Spatial 有限化。三种 Surface 仍分别代表有限自由布局、连续流式布局和无限世界+镜头。

按 2026-09-25 Owner 决定：画布尺寸**整份课件一个**，新建课件时选择（如 16:9、4:3、竖屏、长页），之后修改尺寸时已有内容按比例缩放。本任务与 M21 同批（B14）完成：两者改的是同一套舞台坐标换算，选中快捷条的定位也使用当前画布尺寸，避免坐标代码改两遍。原先依赖 M17 没有技术理由，已改为依赖 M14。

按 2026-09-26 Owner 决定（收敛方案 §7C），本任务同时收口三视图统一，并在 B14 内先于 M21 完成：编辑、当前位置试运行、整课预览与导出 HTML 共用一套页面框（页外裁掉；窗口模式页外为中性灰/工作区色、页面阴影一致，全屏为黑色）；竖屏与长页按宽度铺满、上下滑动，横屏与 4:3 整页显示，编辑态同一规则；插入的媒体按当前画布居中；教师控制器默认按画布放在页面底部居中，编辑与播放使用同一位置规则，选中后快捷条提供展开、收起、隐藏、锁定与 AI 修改；缩略图按实际比例；试运行退出后恢复进入前的页面与状态；无限画布镜头比例跟随课件画布。Flow 编辑与播放的公式、分隔线与组件块画法一致，按屏幕定位的浮层改为相对画布宽度定位，教师控制器在 Flow 页内可选中拖动。默认编辑状态保持“母版”。
