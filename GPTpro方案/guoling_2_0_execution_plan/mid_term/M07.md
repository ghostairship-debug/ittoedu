# M07｜独立会话、统一输入框与可见模型配置

**阶段：中期产品体验 · 2.0 必须完成**  
**实施依赖：** S07、S08、S10、M01

## 输入区

工作台右侧默认常驻AI助手，记录和输入在同一区域；会话列表位于左侧资源管理器下方，默认可见并有明确当前项。不要把主聊天改成画布底部输入框，也不要用右侧模型/运行配置面板代替会话管理。专业编辑器中的AI通过侧边按钮按需展开，见[M03](M03.md)和[交互细则](WORKBENCH_EDITOR_LAYOUT.md)。

常驻用户文字、附件/上下文chips、当前连接和模型、发送/停止。模型可直接切换，强度与服务档放简短二级菜单；目录诊断、原始配置和预算细节放设置。配置失败保留上次有效配置与具体错误，不显示新模型却实际用旧模型。

两现有聊天组件合并为一个Composer/Transcript壳，文档与课件只贡献上下文和工具能力。不要以两个隐藏组件轮流挂载模拟统一聊天。聊天草稿以conversationId保存，不由文件path或CLI adapter key决定寿命。

统一执行不等于只有一个可输入位置：保留M04快捷工具条内的原处AI输入/提交，主聊天是另一入口，二者共用提交规则与任务系统。元素级修改不强制聚焦、展开或跳转到右侧聊天。

## 发送与输入优先级

IME组字优先，打开的@/命令菜单其次，最后处理Enter发送；Shift+Enter换行。鼠标按钮与Enter走同一个submit，submissionId防重复。仅附件可发送，空文字且无附件不发送。

发送后立即出现本地待发送消息卡；后端未接受前，失败可恢复输入和附件。网络超时状态不确定时查询同一submission，不创建重复付费任务。权限首次告知与真正工具授权可以出现，普通消息不多一个确认键。

运行中新消息默认可见排队，显示顺序并可删除未发送项；“立即调整”是明确操作，后端不支持steer时用经确认的停止/接续，不假装已生效。模型自发需要澄清时正常提问，不用应用意图分类器代替。

## 上下文与导航

文件切换不新建会话；当前输入已绑定的文件/选择保持chip并可移除/改为当前。打开历史会话后默认展示其记录，不自动重新打开所有旧文件、恢复所有旧授权或重跑模型。

会话列表按最近时间/搜索组织，标题区可发现新建和搜索，各项菜单可重命名、删除，当前会话明确突出。普通界面不再区分workspace/project/lesson/file会话。标题可手改；自动标题仅辅助，不应额外阻塞发送。

## 错误与可见性

主界面显示影响与可执行下一步：未发送可重试，已应用但未保存可保存，连接失效可重新配置。详情保留真实错误，不把全部错误洗成“未知”。切换模型不会触发长篇原生状态说明突然占据输入区。

## API 主入口与模型角色

对话/规划、视觉理解、图片生成/编辑可以绑定不同供应商和模型。输入区显示实际当前组合及必要缺项，具体 endpoint、认证和 Token Plan/按量费用在设置中可查。高能力开发基准不强制成为用户默认模型。
