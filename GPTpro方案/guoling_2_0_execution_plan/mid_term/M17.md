# M17｜HTML 高保真机械导入与 Runtime 承载

**阶段：中期产品体验 · 2.0 必须完成**  
**实施依赖：** M15、M16、S13

## 完成定义

已有 HTML 的默认导入路径改为“先完整保留，再按收益原生化”。首版允许整页/整块作为 Runtime 进入果铃，导入阶段不得让 LLM 重新理解并重写作品。

## 机械导入

程序解析 standalone HTML、CSS、脚本和受管资源，完成必要路径重写、资源登记、宿主包装和生命周期接线。实现可以使用现有 Runtime carrier 或一个很薄的 HTML document carrier；不得为了名义统一把完整 HTML 硬塞进不适合的 source 字段。

目标 Surface 由上层明确指定。固定展示页可进 Slide，纵向长页面可进 Flow；导入器本身不负责重新做教学或视觉设计。第一版不要求把内部对象拆成 Native，轻编辑复用 M15 自动图文机制。

## 保真与边界

听力案例作为首个真实基准，看初始画面、一个后续状态和一条关键交互，不建设像素评分系统。未授权远程依赖、无法本地化资源和宿主不支持能力必须如实提示，不截图伪装成功。

### M17-T01｜HTML 整体 Runtime 机械导入不调用 LLM

**环境／前置：** 一份本地 standalone HTML，含 CSS/JS/图片/音频或等价资源

**操作：** 通过正式导入入口选择目标 Surface，记录模型调用并完成导入

**验收：** 导入器机械抽取/重写受管资源并整体封装，导入阶段模型调用为零；首版不要求拆 Native，也不要求作者补果铃专用标记

**验证层：** integration；范围：`2.0`；当前状态：`not_run`。

### M17-T02｜复杂 HTML 保真承载

**环境／前置：** 使用听力案例或同等级真实复杂 HTML，固定导入前版本

**操作：** 导入后对照初始画面、至少一个后续状态和一条关键交互

**验收：** 主要布局、文字/译文、图片构图、交互数据与关键行为未因果铃化被主动简化；不以像素级完全一致作为门，也不靠截图替代可运行内容

**验证层：** electron；范围：`2.0`；当前状态：`not_run`。

### M17-T03｜导入 HTML 的图文可继续轻编辑

**环境／前置：** M17-T02 导入工程，Runtime 轻编辑已完成

**操作：** 修改导入 Runtime 中一处文字和一张图片，保存重开并再次运行

**验收：** 修改持久，原互动仍可用；无需把整页转换成原生节点

**验证层：** electron；范围：`2.0`；当前状态：`not_run`。

### M17-T04｜资源与网络边界诚实

**环境／前置：** HTML 同时包含本地相对资源、可内联资源以及一个未授权远程引用

**操作：** 执行导入和离线重开

**验收：** 可本地化资源进入受管资源闭包；未授权远程依赖明确失败或保持声明，不静默联网、不丢资源后称成功

**验证层：** security；范围：`2.0`；当前状态：`not_run`。
