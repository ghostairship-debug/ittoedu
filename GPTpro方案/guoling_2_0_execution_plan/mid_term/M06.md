# M06｜正文即时生成、自动替换与撤销

**阶段：中期产品体验 · 2.0 必须完成**  
**实施依赖：** S06、S07、M05、M07

## 默认路径

在正文选中内容 → 输入要求 → 原位置出现真实生成的新文字 → 完成后自动成为正式内容 → “已修改 · 撤销”。MD和Flow正文必须完成该路径。没有外部候选地址，没有先应用才看得见文字，没有事后打字动画。

## 呈现状态

开始后原区显示轻状态而不是整个文档遮罩。第一个有效内容片段到达即刷新，生成区暂时只读，其余可手改。原文留在编辑组基准，不额外开一个外部预览文件。滚动不强拉到文档底部，用户可随时查看生成位置。

结束后状态依真实操作显示已修改/无需修改/失败。默认完成即提交，无普通编辑确认；生成中停止取消当前未完成组，已完成操作仍在History。Ctrl+Z优先取消活动组，完成后一次撤销恢复该组；人工穿插后正常顺序撤销。

## 行内修订的范围

可选提供本次临时划线原文、新文字插入、应用/放弃。与默认模式共用同一模型输出和EditSession，不多跑一轮。该模式不能保存`<del>/<ins>`装饰进Markdown，不要求完整Word式持久审阅。若实施成本挤占2.0主路径，先不开放可选模式，默认即时替换必须交付。

## 后端与限制

输入区显示所选连接/模型的实际内容流能力。只给完整工具参数的 API 或外部 MCP 调用不能显示“流式正文”。需要替代执行路径时提供明确可用配置，不静默换模型/计费。产品默认稳定路径必须在任务结束前出现真实新文本。

工具级原子操作与正文逐片生成分开：Slides/Spatial按完整操作更新仍是2.0直接编辑；任意画布全步骤演进不混入当前验收。

## 完成条件

正文表现、源文保真、保存和撤销同时验收；只把聊天输出实时显示在一个旁边的框里不算完成。工具文本应进入正在编辑的文档区域，用户可以接着手改。
