# M15｜Runtime／Component 轻编辑与自动图文发现

**阶段：中期产品体验 · 2.0 必须完成**  
**实施依赖：** M14

## 完成定义

先完成当前剩余旧验收并固定稳定基线，再打开这一轮 2.0 增量。目标不是把 Runtime 变成完整网页开发器，而是恢复“运行到哪里即可返回哪里编辑”的产品闭环：当前状态中的文字和图片可选、可改、可撤销、可保存重开。

## 实现边界

宿主负责自动发现，不再要求生成 AI 为每处图文手写 expose。DOM 优先自动识别可见文字与图片；Phaser 适配常用 Text/BitmapText/Image/Sprite；Three 只覆盖明确可识别的简单纹理/文字模式，复杂 WebGL 保持黑盒。Scene Runtime 与 Component 复用一套轻编辑目标和提交抽象。

持久化只覆盖 text/image 等轻量修改和已有正式字段。必要时允许宿主保存窄 authoring patch，但不做任意 DOM/CSS/JS 源码反编译，不保证 Runtime 源码整体重写后旧目标仍自动迁移。

## 停止条件

文字/图片闭环成立即停止扩展；不在 2.0 增加任意 CSS 属性、任意动画帧、任意 JS state、通用 Three 场景编辑或复杂视觉设计器。

### M15-T01｜运行到哪里即可返回哪里轻编辑

**环境／前置：** 含动态状态的 Runtime，编辑/试运行共用同一工程

**操作：** 试运行推进到非初始状态，返回编辑后修改当前可见文字和图片，再继续运行

**验收：** 返回编辑时保留可识别的当前业务状态；修改无需重建整份 Runtime，继续运行不破坏原交互

**验证层：** electron；范围：`2.0`；当前状态：`not_run`。

### M15-T02｜无需 AI 显式 expose 的自动图文发现

**环境／前置：** 准备未写 authoring.register/data-courseware-edit-key 的 DOM、Phaser 常用 Text/Image/Sprite，以及一个受支持 Three 简单模式

**操作：** 由宿主进入轻编辑并点击可见图文

**验收：** DOM 与 Phaser 常用图文自动成为目标；Three 只对已支持模式出现目标，复杂 WebGL 不伪装可编辑；生成模型无需逐项声明

**验证层：** integration；范围：`2.0`；当前状态：`not_run`。

### M15-T03｜文字图片修改可持久化

**环境／前置：** 自动发现目标可选择，Runtime 会发生一次 rerender

**操作：** 修改一处文字与一张图片，触发 rerender，撤销/重做，保存关闭重开

**验收：** 修改在 rerender 后仍生效并进入既有 History，重开后保持；只持久化 text/image 轻量补丁或既有正式字段，不反向编译任意源码

**验证层：** integration；范围：`2.0`；当前状态：`not_run`。

### M15-T04｜Scene Runtime 与 Component 共用轻编辑机制

**环境／前置：** 一个场景 Runtime 和一个 Component 均包含可见图文

**操作：** 分别进入编辑、修改、保存重开

**验收：** 复用同一轻编辑目标/提交抽象，允许 adapter 差异但不维护两套用户编辑器；锁定/只读目标不写入

**验证层：** electron；范围：`2.0`；当前状态：`not_run`。
