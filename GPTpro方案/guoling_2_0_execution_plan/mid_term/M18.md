# M18｜可靠课件初稿与人主导局部精修

**阶段：中期产品体验 · 2.0 必须完成**
**实施依赖：** M15、M16、M17、M19、S14、M23、M24

## 当前完成定义（2026-09-29 可用性修复）

依据根方案 §7G，两个按需 Skill 的默认交付改为教学表达完整、可演示、可编辑、已保存的初稿。默认不自动全课视觉精修，不要求两次阶段确认、四份中间稿或每页过关。用户要求阶段审阅、自主学习或完整精修时按其要求执行。

## 当前流程

简短策划 → 核心图示与页内机制完整的 HTML → 由唯一 Slide 目标的导入器自动映射（多表面按明确目的地）→ 正式准入和保存 → 文件字节回读。HTML Runtime 保持已有图文轻编辑，不用额外 Native 按钮覆盖已导入按钮。详细讲稿、表示规划与额外导出按需。

初稿交付后由人选页或对象精修。图像观察和功能诊断能力保留；无核心教学呈现、资源丢失、无法保存或必需互动缺失不能标为 completed。外部 Builder V2 完整方法保留为按需参考，内置通用系统提示词不写入教学流程。

## 历史证据与当前增量

下文 M18-T01—T05 保留 2026-09-27/28 原范围的已通过事实与验收原文，不再定义当前默认创作步骤。此次默认行为变更由新增 M18-T06 单独验证；旧真实运行的 partial、人工介入和未签收边界继续保留，不能从旧状态推导本轮 Owner 接受。
