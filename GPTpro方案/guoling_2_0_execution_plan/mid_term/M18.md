# M18｜框架 HTML 创作链与后置表示规划

**阶段：中期产品体验 · 2.0 必须完成**
**实施依赖：** M15、M16、M17、M19、S14、M23、M24

## 完成定义

2026-09-27/28 Owner 决定（收敛方案 §7D）：果铃内置 AI 是通用 Agent，系统提示词不放课件创作链。创作链写在 `orchestrate-courseware` 与 `build-courseware-project` 两个 Skill 中，内置 AI 经 M24 按需读取，外部 CLI 使用同一份 Skill。

## 流程

1. **教学策划：** 写 `01-teaching-plan.md`，教师确认①。
2. **框架 HTML：** 整课一个文件，`<body>` 下每个 `<section>` 一页；每节按内容选固定画布、流式长页或镜头编排中最合适的呈现。只呈现布局与大致功能：图片、音视频写成没有 `src` 的 `<img>`、`<audio>`、`<video>` 并写明需要什么，不生成素材；不引用远程脚本或 CDN，交互直接写在页面里。另附一页讲解与操作说明，只写 HTML 表达不了的内容（教师怎么讲、学生怎么做、教师控制与评价）。在工作台预览（M23），教师确认②。框架 HTML 确认前不读取编辑器能力。
3. **表示规划：** 到这一步才读短能力说明（不超过 1,500 字符，只写做表示选择必需的信息），逐节决定表面（演示页 / 流式讲义 / 无限画布）与原生 / 素材 / 互动页表示（必要时注明 Runtime 引擎），写成 `03-representation-plan.md`。一次薄规划，不增加评分 Agent、架构复审或多轮门禁。
4. **导入与组装：** 按页拆分导入（M24），一页进一页，不挤在一个场景；按占位说明生成或放入素材；补必要的原生对象；不让模型照 HTML 重写整件作品。固定画布页进演示页；流式长页进讲义（Flow 只收自然排版，不满足时用原生对象重建）；镜头编排页用无限画布的原生区域与镜头重建，复杂区域放互动页。
5. **视觉精修：** 框架只是大体框架，组装后必须逐页看真实画面（M24 看页面），修排版、字号、对齐、溢出与配色；原生对象用编辑工具修改，互动页改源码后重新过准入。
6. **保存、重开、交付：** 说明做了哪些假设、哪些要求没有做到。

## 两种模式与不降级

- **默认：** 在①②处各确认一次；信息不足时用弹窗选项补问。
- **自动：** 用户明确写“根据材料自动创作”时跳过全部确认，也不提问；中间稿照写，缺的信息按合理假设处理，直接做到保存好的成品，交付时列出假设。
- **不降级：** 用户明确要求按材料要求实现时，材料的每项要求都要完整实现，不简化、不删减、不换成静态图，表示规划选做法时同样遵守；确实做不到时，自动模式在交付时逐条列出原因，默认模式发现时先弹窗询问。
