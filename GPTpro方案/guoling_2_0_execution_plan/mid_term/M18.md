# M18｜理想呈现后置的 Representation Planning 与创作链

**阶段：中期产品体验 · 2.0 必须完成**  
**实施依赖：** M15、M16、M17、M19、S14

## 完成定义

教学设计与理想呈现阶段不读取编辑器能力说明。模型先决定怎样教、怎样呈现，并可先形成高质量框架 HTML；之后再单独读取一份短 Capability Profile 做一次 Representation Planning。

## 表示规划

输出只需给页面/区域选择 Surface（Slide / Flow / Spatial）以及 Native / Asset / Runtime，必要时标明 Runtime engine。规则保持简单：简单独立且高频手改的对象优先 Native；纯视觉结果为 Asset；共享布局、状态或复杂交互的完整区域优先 Runtime。

已有完整 HTML 默认允许整体 Runtime。原生拆分是有编辑收益时的优化，不是导入前提。执行阶段由机械 importer / asset / layer 工具完成，不再让模型照 HTML 二次重写整件作品。

## Skill 顺序

course-design 只做教学与呈现；layout/presentation 输出理想框架；representation planner 才第一次读取编辑器能力；slot/build 只完成必要素材与实现。保持单次薄规划，不增加评分 Agent、架构复审 Agent 或多轮门禁。
