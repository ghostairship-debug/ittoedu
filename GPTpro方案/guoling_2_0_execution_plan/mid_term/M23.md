# M23｜工作台 HTML 预览与轻编辑

**阶段：中期产品体验 · 2.0 必须完成**
**实施依赖：** M15、M17、M20、M21

## 完成定义

2026-09-28 Owner 决定（收敛方案 §7D）：工作台直接打开 `.html`，默认预览；点笔形按钮进入轻编辑，不用导入编辑器就能改字、换图并即时生效（热更新）。M18 的框架 HTML 在这里给教师预览和确认。

## 用户行为

- 资源管理器双击 `.html` 在工作台标签中打开（当前是交给系统浏览器），默认预览，可切到源码；源码按纯文本文档编辑、撤销与保存，沿用 M20 的字节保真。右键保留“用浏览器打开”和“作为互动页导入”。
- 分页：`<body>` 下每个 `<section>` 是一页（允许外包一层 `<main>`），逐页翻看：上一页、下一页、页码、方向键。固定画布页整页缩放适配，流式长页上下滚动，镜头编排页运行页面自己的逻辑；AI 不需要标注页面类型。不分页的 HTML 整页显示。
- 笔形按钮轻编辑：悬停高亮可改的文字与图片，双击改字，点图换图；快捷条与编辑器同源，带“AI 修改”（元素 AI 卡，改的是这份 HTML 的源码）。改动原地生效，页面状态不丢；文件标为未保存，Ctrl+Z 撤销。
- AI 新建或修改 `.html`（`file.create`、`text.replace`）后，预览自动刷新并停在当前页。没有 `src` 的 `<img>`、`<audio>`、`<video>` 按占位框显示其说明文字（M18 框架 HTML 的占位写法）。

## 实现要点

- **隔离：** 预览页使用独立来源（自定义协议 + 跨源 iframe），与编辑器不同源，不注入 preload；只提供该 HTML 所在文件夹内、realpath 闭合的文件，访问令牌随标签关闭失效；不能导航顶层窗口，新窗口交系统浏览器或拒绝。主界面 CSP 只多放行这一个来源。网络规则与 M17 分类一致：远程图片、音视频可加载并提示离线不可用，远程脚本、样式、字体不加载。涉及 Electron 主进程、协议与主界面 CSP，属敏感变更。
- **编辑通道：** M15 的识别代码直接读同源 iframe 的 DOM（`src/player/lightEdit/htmlDocumentRoots.ts:14`），跨源后读不到。预览时由软件注入一个编辑代理（只在预览响应中注入，不写进文件），在页面内复用同一套自动识别与原地生效逻辑，通过消息把目标位置报给工作台，高亮与快捷条由工作台绘制。
- **写回源码：** 独立 HTML 没有课件可存覆盖记录，修改写回文件本身：文字在源码中定位后替换（按原文与所在元素消歧，有歧义时要求重新选择，不批量替换同名文字）；图片存到 HTML 同目录的素材文件夹并改 `src`。每次修改是该文本文档的一次正式事务，撤销、保存与外部修改冲突沿用现有语义。脚本生成、在源码中找不到的文字标为“不能直接修改”，可以用 AI 修改。
- 不新增依赖（产品代码不 import jsdom、parse5）；源码定位优先复用 M17 导入器的标记扫描。

## 停止条件

不做通用浏览器调试器、控制台、网络面板或任意 CSS/布局可视化编辑；复杂修改交给 AI，或导入编辑器后进行。

### M23-T01｜HTML 预览与编辑器隔离

**环境／前置：** 工作空间中一份 HTML，含本地图片、内联脚本、一个远程脚本、一张远程图片，并尝试读取所在文件夹以外的文件与编辑器接口

**操作：** 在资源管理器双击打开，操作页面交互，关闭标签后再尝试访问

**验收：** 在工作台标签内默认显示预览并真实运行；远程脚本不加载，远程图片可显示并提示离线不可用；页面拿不到编辑器接口、读不到所在文件夹以外的文件、不能跳转整个窗口；关闭标签后访问失效；右键仍可用浏览器打开或作为互动页导入

### M23-T02｜分页预览三种呈现

**环境／前置：** 一份整课分页 HTML：body 下多个 section，含固定画布页、流式长页与镜头编排页

**操作：** 逐页翻看（按钮与方向键），在预览与源码之间切换

**验收：** 固定画布页整页适配，流式长页可滚动，镜头编排页自身动画照常运行；页码正确，切到源码再回预览仍停在原页

### M23-T03｜笔形按钮轻编辑与热更新

**环境／前置：** M23-T02 的 HTML，页面内有一个会随操作变化的交互状态；本地假模型

**操作：** 点笔形按钮进入轻编辑，双击改一段文字、替换一张图片，用快捷条“AI 修改”改一段文字，撤销一次，保存后关闭重开

**验收：** 改动立即在预览中生效且页面状态不丢；改字写回源码对应位置，新图存到 HTML 同目录的素材文件夹并更新引用，其余字节不变；Ctrl+Z 可撤销；AI 修改后预览刷新并停在当前页；脚本生成的文字标为不能直接修改；重开后修改保持

**验证层：** electron；范围：`2.0`；当前状态：`not_run`。
