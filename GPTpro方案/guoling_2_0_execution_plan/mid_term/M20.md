# M20｜文件与会话细节：新建菜单、纯文本文档、另存为与会话所属

**阶段：中期产品体验 · 2.0 必须完成**  
**实施依赖：** M14

## 完成定义

修正 2026-09-25 Owner 在工作台实际使用中指出的文件与会话细节：资源管理器的新建菜单要能区分 Markdown 文档与文本文档，文本文档能在工作台内打开编辑；课件轻量顶栏提供另存为，进入编辑器的按钮改名为“编辑器”；右侧会话头明确标出本会话属于哪个工作空间、文件夹或文件。

## 实现边界

- **新建菜单**：依次为新建 Markdown 文档、新建课件、新建文本文档、新建文件夹；资源管理器“新建”与右键菜单一致。名称框预填默认名（如“新建文本文档.txt”），只选中主名；未写后缀时自动补 `.md`、`.h5lesson`、`.txt`，用户主动写的其他后缀保留。新建成功后直接在标签页打开。
- **纯文本文档**：作为与 Markdown、V9 并列的正式文档类型，读写沿用 Markdown Driver 的逐字节保真（UTF-8，保留 BOM 与换行）；编辑器复用现有源文编辑，不带排版模式。保存、另存为（默认 `.txt`）、撤销、崩溃恢复与冲突处理走同一 DocumentSession。第一版只收 `.txt`；非 UTF-8 文件明确提示并提供“用系统程序打开”，不做转码写回。AI 文件工具可读取、修改、新建 `.txt`，不套用 Markdown 语义。
- **另存为与按钮名**：课件轻量顶栏在“保存”旁增加“另存为”，顺序与 Markdown 文档头一致，复用现有另存为能力与 Ctrl+Shift+S；右上角进入编辑器的按钮改名为“编辑器”。
- **会话所属**：会话头标题下显示“工作空间 › 文件夹 › 文件”及类型图标，悬停显示完整路径；它只代表默认引用和新建文件位置的优先级，不限制 AI 可修改的范围，也不加“当前文件不在所属范围”的提示。空会话标明“发送首条消息后固定”，已删除和已移到其他工作空间的状态可见；点击可在资源管理器中定位。

## 停止条件

不扩展为通用代码编辑器或多编码转换工具；`.csv`、`.json` 等其他文本类型以后按需加入。
