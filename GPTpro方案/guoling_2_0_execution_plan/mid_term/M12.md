# M12｜首次使用与连接设置

**阶段：中期产品体验 · 2.0 必须完成**  
**实施依赖：** S05、S08、S10、S11、S12、S13、S14、M07、M08、M09

## 首次使用路径

打开应用 → 直接看到可新建/打开的工作台 → 配置一条AI连接 → 添加材料与发起任务。先可打开和手改文件，不用配置CLI才能进入软件。连接准备完成后有最小验证任务，验证身份、可用模型、真实输入和直接工具。

连接设置首先提供 API 地址、Key、模型与计费来源，包括允许的 Token Plan；按角色配置文本、视觉、图片。OAuth 为可选登录，外部 MCP 注册配置单独呈现。连接列表显示实际可用/未配置/认证失效/能力不足，不要求安装 CLI。配置、模型和费用来源可查，凭据不进入渲染网页或诊断默认日志。

当前本地产品构建至少有一条无需开发者现场指导即可建立的稳定连接，可是用户自己的已授权连接或应用合法提供的服务。订阅/API/代理费用与权限分别验证；不承诺把团队账号或个人订阅权益直接提供给其他用户。

## 权限与告知

首次必要说明用少量用户语言：哪些内容进入外部服务、已知服务方、工作区读写范围；详情可展开。后续同范围发送不反复确认。实际工具扩大权限仍需明确授权。不能把cwd宣传为沙箱，也不能宣称知道后端未暴露的所有动态读取。

## 故障处理

网络断开/额度限制/登录过期/模型下线有明确状态，当前稿与输入附件保留。引导用户调整连接或重试同任务，不要求去磁盘找candidate。反馈入口能导出脱敏诊断和版本信息，由用户主动选择是否附文档。
