## 连接能力

每个内置连接记录 Provider/SDK 版本、实际 endpoint/模型、认证、计费来源、工具调用、正文流、文字/公开摘要、图像输入/生成/编辑、限流与恢复。外部 MCP 另记客户端版本、传输、schema、资源返回、撤权与可见事件；不将其视为内置模型连接。Provider 能力事实状态遵循 `ModelCapability` 合同，仅为`unknown / supported / unsupported`。`experimental` 只用于产品能力成熟度的说明标签，表示该产品能力仍处于试验阶段；它不是 Provider/连接的能力状态，不写入 `capabilities` 字段，也不能代替实际验证结论。验证结果另用`not_run / passed / failed / blocked`；能力事实、成熟度说明与验证结果不能混用。

连接显示为稳定可用，意味着其声明支持的能力有实际运行记录。上游只提供思考摘要就显示摘要；未提供工具参数增量就不伪造；普通工具调用完成即更新不等于逐token正文流。

统一自建执行器使用用户配置的模型角色连接；缺失能力可选择已授权的其他连接，不保证某一模型通吃所有任务。API/Token Plan 与低成本生产是主链，OAuth 为可选入口。切换模型/供应商/计费必须可见且获得授权，不静默降级；不能把没有正文实时路径的配置宣传为实时编辑。中期发布至少有一条完整覆盖核心需求的已验证连接组合，且已支持的其他连接不得出现未说明的回归。

## 直接编辑操作范围

工作台提供文字、图片、视频、音频插入和资源树媒体拖入，选择后以快捷工具条/属性浮层修改。保留快捷工具条内就地 AI 修改，与主会话共用执行与正式文档变更。Slides/Flow/Spatial 分别使用已有合法 carrier；完整导航、轻量手改和专业编辑器往返见[交互细则](mid_term/WORKBENCH_EDITOR_LAYOUT.md)，不创建第二份内容模型或 History。

文本替换、对象公开属性、位置/样式、同文档批量编辑和结构操作，不产生外部候选交付。工具内部保留身份、权限、输入、资源、读写集合和幂等检查。模型需要看结果时可调用观察，应用不为所有操作追加固定模型审查。

生成新Runtime/组件代码、导入完整工程、难转换外部格式，允许专项准备与检查。返回结果必须留在软件内预览/应用，不能让用户去读取临时路径。

## 尚不属于2.0的承诺

完整DOCX/PPTX/XLSX原生回读编辑、任意PDF如Word编辑、任意HTML保真转换、全部画布步骤逐token可视化、多人实时协作、持久审阅修订、任意代码仓库的通用开发平台与自动接管外部 CLI 生命周期。这些方向见`long_term/`；现有可用导出与高级课件编辑需要继续保全。
