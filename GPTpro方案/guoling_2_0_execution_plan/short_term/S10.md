# S10｜空间、独立会话与模型角色配置

**阶段：短期基础设施 · 2.0 必须完成**
**实施依赖：** S02、S07、S08、S09

## 交付物

Workspace → Files 与 Conversations 并列；Conversation 可引用多文件，Task 属于会话并引用明确文档。项目/课例不暴露成另一套聊天入口。旧聊天、旧缓存及其索引不迁移。

界面沿用左上角工作空间新建/切换入口，不新增与空间同义的强制项目层级，也不删除h5lesson内部Course Project身份。工作台左侧资源管理器在上、会话列表在下，右侧显示当前会话的AI记录和输入；具体布局由[M01](../mid_term/M01.md)/[M07](../mid_term/M07.md)与[交互细则](../mid_term/WORKBENCH_EDITOR_LAYOUT.md)规定。布局不改变文件与会话的正交关系。

## 状态归属

Workspace 含稳定 ID、根路径/受管空间和授权；Conversation 保存标题、消息、附件快照、run 索引及草稿。正式正文只由文档服务持有。用户原话、必要历史、已提交事实与剩余任务支撑续接，不依赖外部 CLI thread。

ExecutionProfile 按角色记录连接/模型/effort/服务档：对话与规划、视觉理解、图片生成/编辑可分别指定。模型不支持图片时使用已配置的视觉路径并标明来源，不悄悄只发文件路径。Connection 的凭据为安全存储引用；认证 api-key/oauth 与计费按量/token-plan/订阅/预付/未知分开。

请求配置、实际执行配置与下一轮配置分开保存；运行中改设置只影响明确的后续请求，不重写历史模型和用量。默认最近有效配置不随打开文件分叉，缺失角色配置可按已知能力推导并清楚显示，不自动选择新收费来源。

## 操作与删除

打开会话只改变 AI 区，打开文件只改变内容区。输入中已绑定目标保持可见；发送时冻结，新会话不自动引用所有已打开文件。删除会话停止其内置 run、撤销相关外部授权并释放自身缓存引用，不删除用户文件或外部 AI 历史。文件删除与空间关联移除分别处理。

恢复仅恢复果铃 2.0 自身记录和用户内容，不自动启动付费模型。外部交接由 S12 的单独 connection/grant 记录引用当前文档，不导入外部私有会话或令牌。

## 外发与告知

输入区左下显示当前权限档位，右下显示实际服务、模型与计费；设置中可查计费来源、模型角色和授权。发送前不弹服务说明（2026-09-24 Owner 决定），发送时冻结权限与路由。输入附件清单与工具动态读取记录分离，不把初始附件列表宣称为全部未来外发内容。

## 权限档位

四档：完全访问 / 完全访问（工作空间，默认）/ 修改前询问 / 只读（2026-09-24 Owner 决定）。档位随任务冻结，由主进程执行：只读不提供修改工具；修改前询问对每次修改先弹批准卡，允许后才提交，拒绝则文档不变并把拒绝交给模型；工作空间档对工作空间内的修改不询问、对工作空间外先询问；完全访问不询问。运行中切换档位只影响之后发送的任务。
