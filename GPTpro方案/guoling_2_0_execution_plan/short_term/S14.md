## 流程

发起前冻结模型、实际图像路由、参考图、目标用途与有效输出参数；模型能力矩阵区分看图、生图、编辑、多参考图、透明背景、尺寸与输出格式。不因为兼容 endpoint 接通就宣称所有能力成立。

请求进入持久 job；显示真实进展，保留 request ID 与用量。超时但状态未知时查询可查询任务，不能自动重发可能重复收费的图片请求。停止后晚到图片可作为未应用结果记录，不能自动写原文档；供应商已发生费用不虚报取消。

收到图片后校验解码、实际格式/尺寸和可用性，纳入资源服务；向模型返回紧凑引用及必要预览，不反复塞 base64。用户可明确选择插入/替换或任务已授权自动使用，均经 Gateway 和文档事务。附件参考图原件不被覆盖。

资源被文档、撤销记录、会话/未完成任务引用时不清理。保存/重开/离线导出不依赖供应商临时 URL；图像失败不以 SVG/代码绘图冒充生成成功。

前期代表性组合为 DeepSeek 文本 API + 已明确配置的图像连接，视觉按所选连接的真实能力配置；须有真实完整生产记录。GPT 图像同时可用作质量基准，OAuth 图像按具体可用型号分别验证生成与编辑，不后台切换 API 收费。2026-09-25 决定已授权 TeamoRouter 图片 API，并按上述通用 Images API 子集适配器方案实施；新适配器仍须按同一能力矩阵单独验收。
