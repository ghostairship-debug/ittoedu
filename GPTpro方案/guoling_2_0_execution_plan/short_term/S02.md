# S02｜每文档会话内核与视图解耦

**阶段：短期基础设施 · 2.0 必须完成**  
**实施依赖：** S01

## 目标与交付物

创建主进程 DocumentRegistry 与纯 DocumentSession，MD 和 h5lesson 均可多开、未保存编辑、非前台修改。renderer 的 Store 与各表面 backend 改为 session 投影。规划模块：`src/core/documents/`、`src/main/documents/`、`src/renderer/documentHost/`；名称可等价替换，职责与依赖不能混淆。

## 核心数据

`DocumentId` 稳定，`binding` 为 file/untitled，`revision` 是内容版本，`epoch` 是当前会话寿命。每份文档自己的资源引用、撤销、未确认修改队列和任务租约都以 DocumentId 为键。文件内的 projectId 仅是格式身份，不作为全局文件身份。

`ViewState` 包含 locationId/stateId、缩放、滚动、手动 selection 和深度编辑状态；仅变更 ViewState 不增加内容 revision。一个文件只建立一个权威 session，同文件多次打开复用；独立副本用不同 DocumentId。

## 实施顺序

1. 从 `EditorStoreKernel` 抽出不依赖 React/Electron/DOM 的内容读取、纯规划和正式提交端口。将依赖浏览位置的 `readAuthoringSession` 从内容写入前置条件移到视图适配。
2. 给每个文档建立 DocumentDriver。Markdown 以保真 source 为权威、缓存 sourceMap/解析树；h5lesson 沿用 V9/资源侧车。不要把 MD 转成 V9，不创造全格式超级 schema。
3. 将纯领域 planner 迁出 renderer。渲染测量、字体测量和代码观察不得在 main 伪执行；需要它们的专门操作使用异步观察端口，普通属性操作不依赖已挂载画布。
4. main 暴露 `open/create/read/dispatch/subscribe/save/close` 窄 IPC。renderer 人工输入先更新本地未确认投影，再按单文档序列送出；回复按 operationId 对齐。AI 发起前 drain 该文档已有人工队列，而不是强制磁盘保存。
5. 拆掉 `editorStore` 中单一可写课程的假设。各表面 connector 根据 documentId 获取内容；后台没有挂载 Phaser 也可以修改已知对象。隐藏视图按需挂载，切回读取最新投影。
6. 重写 destination resolution：由目标文档及其中对象解析 surface/location/owner/state，不从当前 UI scope 复制。已有 domain owner 规则保留，视图选择不成为写权限。
7. 新建 MD/课件直接建立内存 session。首次保存只绑定路径；Save As 默认重绑定当前文档且旧文件保留，显式“复制一份”才新建 session。关闭仅当前文件，不清空会话。

### B01 内部检查点

与 S03 共同推进，以下只用于多会话交接，不增加批次、完成归属或验收用例：

1. 纯 TypeScript 内核及 Driver 的针对性单测通过，不依赖 Electron/React/DOM；交接可复现命令与行为证据。
2. 主进程 DocumentRegistry 与窄 IPC 接通，两份课件和一份未保存 Markdown 同时存在，各自身份、revision、订阅与操作队列隔离。
3. renderer 投影与薄 V9 Driver 接通；真实验证非当前页修改、撤销、保存重开，证明视图切换不偷换目标。事务与恢复证据由 S03 同步补齐，前两个检查点不代表 B01 完成。

## 同步规则

未确认手改不是第二套正式文档：不能自行写盘、不能向 AI 声称已提交。拒绝请求后恢复到权威 revision 并保留用户输入；断连时保留局部草稿且停止对旧版本的 AI 写入。

读取 AI 目标时取 `flushDraft→readSnapshot`，不是 `flushToDisk`。同一文档写操作串行，不锁所有文档。跨文件模型任务需要分别读取句柄并操作，切标签不改变任务对象。

## 退出条件

所有默认路径中，不存在因“当前页不同/当前标签不同/没有 projectPath”而拒绝合法文档操作的条件；多份课件不复用可写单例。特殊渲染能力无宿主时可以明确要求观察，但基础文字/属性/结构操作必须能执行。
