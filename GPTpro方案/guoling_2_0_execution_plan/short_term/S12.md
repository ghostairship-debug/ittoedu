# S12｜外部 MCP 开放、授权与任务交接

**阶段：短期基础设施 · 2.0 必须完成**
**实施依赖：** S04、S07、S09

## 交付物

一个果铃 MCP Server，外部 Codex、Claude、OpenCode 及其他支持客户端调用同一 ToolCatalog/Gateway。只维护客户端注册、配置与协议兼容，不深度嵌入模型菜单、原生事件或完整会话循环。

## 桥与文档服务

内部执行器直接调用 Gateway，外部由 MCP wrapper 暴露同源 schema；只有协议封装不同。标准 read/list/inspect、局部修改、资源引用、操作查询与保存接同一权限和回执。构建/图像工具在 S13/S14 就绪后由目录自动发布，相关集成在 S11 验收，不倒置 S12 依赖。

本地优先 stdio 薄 bridge 或 loopback Streamable HTTP。多个客户端的 bridge 均附着同一主进程文档服务；不因客户端启动 bridge 而新建可写 Registry。HTTP 使用实际身份校验、短期授权和来源校验，预览页面无桥/凭据。云客户端不能访问本机时明确不支持，不把任意隧道设成默认前提。

## 授权、重试与交接

每条 connection 和任务有独立 grant/epoch、读范围与可写目标。RPC request ID 只负责传输关联；可重复操作另由宿主生成 operation ticket/幂等键。票据可在授权/观察结果中预发，普通写入仍可一次工具调用提交；重试复用已返回票据查询结果；同票据重发返回原回执，文本相同的新意图不能被误去重。

撤权/关闭/停止先使旧授权失效，晚到调用拒绝。读到的文档状态和版本不再成立时重新观察或冲突，不偷换成当前焦点。

交接包包含用户原话、目标引用、已提交事实、剩余任务、必要附件和重新观察入口。交接前结算内置 run，外部取得新授权后工作；模型不从旧文字推测提交是否成功。S12 的 MCP 交付本身不承诺果铃自动启动外部 CLI 或无损接管其私有上下文。

2026-09-24 Owner 决定：内置任务中途交给外部 AI 接手不作为 2.0 验收，原 S12-T04 与 REL-T12 删除。外部客户端直接读写同一文档、票据与撤权仍由 S12-T01～T03 验收；已实现的交接包入口保留在授权面板中，但不作为 2.0 发布承诺。

后续允许通过薄 runner 主动启动外部 Agent，作为单独的作业能力；不禁止 CLI，也不恢复三套深度业务集成。委派时父任务等待子任务，交接时旧 run 已结算，两种生命周期分别处理。runner 管启动、有限事件、取消与结果收集，文档读写仍经本节的同一 MCP/Gateway；授权撤销、外部进程终止和磁盘变化分别记录。详细后续约束见 [L03](../long_term/L03.md)。本补充不增加 S12 的任务、依赖、验收或当前 runner 实现要求。

## 能力边界

外部客户端的完整思考、聊天、用量、逐 token 正文与停止不由 MCP 保证；只显示实际可见信息。MCP 不限制外部 CLI 自己的 shell；磁盘旁路变化按 FileService 重载/冲突处理，不能标为宿主已提交。

至少两种客户端实测同一 Server 的发现、读改、资源结果、幂等与撤权；每种声明支持的传输/客户端都需有兼容记录，未知能力不标为稳定。
