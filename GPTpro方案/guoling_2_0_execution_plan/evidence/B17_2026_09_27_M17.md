## 失败、修复与验证边界

- 早期实现把一切远程媒体阻断，和 Owner 的产品边界及架构合同第 155 条不符。已按主动脚本与被动媒体用途分类；旧“远程图片/音频应失败”测试结果已失效，不用于当前结论。
- Flow 长页曾因测量两轮共用 3 秒总截止而误报“布局持续变化”，见 `flow-html-import/run-d3nDoa/`。调度改为单飞与局部有界等待；聚焦调度测试 5/5、Chromium 长页正例及 resize 删除正文负例 2/2，由切片执行者实跑；最终由主会话在真实 Electron 主链 1/1 复核。早期卡片定位、立即读高度和未滚动点击也分别改为按实际 DOM 与可见视口操作；失败轮没有计入通过。
- 该切片首次 diff 静态审查发现 null source 悬挂、跨文档失效预算继承和预期根 resize 误计数，未合入；修齐后 Astra GO。原 1 ms 属性更新用例被改成确定性的 `data-tick` 可见颜色变化 13 轮拒绝用例，没有把持续变化放行。
- 收尾 `npm run build:renderer`、`npm run typecheck`、`npm run check:g20-import-boundaries`（960 sources、5828 edges、0 violation）、`npm run check:contracts`（4 项）均 exit 0。首次 `check:ai-capabilities` 报溯源过期，按规定 `generate:ai-capabilities` 后复查 exit 0。新增离线重开断言后 `npx tsc -p tsconfig.e2e.json --noEmit` exit 0；未因该测试编辑重跑无关产品矩阵。
