## M21-T02｜统一选中快捷条

- **演示页。** 选中文字后，快捷条出现在对象上方，不与对象重叠。条上有编辑文字、加粗、斜体、下划线、字号、文字颜色、高亮、对齐、AI 修改和“⋯”；没有数值输入框，工作台里也没有“属性”页签。
- **拖动与缩放。** 按住对象拖动、按住东侧手柄缩放时，快捷条隐藏（`data-suspended`）；松手后回到对象旁。
- **锁定。** 从“⋯”锁定后，条上显示“已锁定”和就地“解锁”；点解锁后恢复。
- **无限画布与编辑器。** 在无限画布上用右键“全选”选中世界文字，快捷条与演示页相同。在编辑器中选中同一对象，快捷条按钮清单与工作台完全一致。
- **讲义。** 纸面浮层给出同一套对象快捷条。单击正文图片会选中整块，条上是“替换图片、上移、下移、AI 修改、⋯”，与页面对象同序。跨两个单元格选中表格文字，给出选区文字工具。在段落里双击选词，给出“选中内容快捷工具”。

三处入口行为一致：

- **对象“文字颜色”。** 先弹出“常用色”和“项目色”，此时没有连续调色器；点“更多颜色…”才出现“自定义颜色”。取色 #123456 后，标题文字即为该色，色板随之关闭；再次打开，“最近使用”里有 #123456。

## 运行中发现并修复的缺陷

| 缺陷 | 修复 |
|---|---|
| 点右键菜单项不生效：菜单通过 portal 渲染，但仍是舞台的 React 子节点；舞台的 pointerdown 捕获处理按菜单项位置重新命中测试、抢占指针并清掉选中 | c55d90bf：舞台只处理 DOM 上在舞台内的按压 |
| 拖动或缩放对象时快捷条不隐藏：舞台的 React 捕获处理在 React 根容器处截断事件，挂在舞台上的手势监听收不到 | c55d90bf：改在 document 捕获阶段监听 |
| 图片的右键菜单出现“编辑文字” | c55d90bf：主操作与快捷条一致 |
| 在编辑器里打开另一文件后返回，之前在编辑器里看过的文档回到工作台时仍带编辑器外观 | c55d90bf：不在编辑器焦点时一律为轻量外观 |
| 单击讲义正文里的图片不会选中（ProseMirror 只在 Ctrl+点击时选中带内容的块），快捷条出不来 | c55d90bf：单击对象本身即选中整块 |
| 页面多时“+”随卡片滚出视野 | c55d90bf：固定在页面栏右端 |
| 资源管理器右键与“新建”菜单是旧样式，不显示不可用原因 | c55d90bf：改用统一命令菜单 |
| 讲义对象条上“⋯”在“AI 修改”之前；正文对象没有右键菜单 | 221f4662：同一命令表，“⋯”在最后，并加右键菜单 |
| 文字编辑中先开文字颜色再切高亮，高亮色板列出的是文字颜色的最近值 | 221f4662：两种色板各自独立 |

手势监听、图片菜单主操作、编辑器外观、正文对象单击选中与编辑态色板五项各有单测，且这些单测在修复前会失败。讲义对象命令表与右键菜单有新增单测；资源管理器菜单更新了既有单测。舞台 portal 按压与“+”固定两项没有单测，由上面两份 Electron 用例覆盖。
