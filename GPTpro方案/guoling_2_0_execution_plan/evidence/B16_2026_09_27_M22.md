## 发现与边界

验收中修正了行距渲染异步观察、空白页以正式 `sceneId` 查找、预览就绪等待；预览首击此前不触发音频。源码检查发现编辑器 Phaser 会接收预览层的窗口鼠标事件，`9d0ae643` 只关闭该编辑器实例的 `windowEvents`，不改 Runtime 或音频执行器。修复后 M22-T02 首击、跳转与导出 1/1 通过。

两份 M22 run 的 `evidence.json` 在 `finally` 里有 `documentError`：采集器沿用关闭前的旧 `documentId`。正式用例分别读取新 ID，保存重开断言均通过；此项是辅助采集缺口，不作产品通过或失败证据。M21 run 没有模型请求计数，部分精确耗时仅有 Playwright 的分钟显示。复杂互动、动画、精确数值和组件编辑仍按既定边界进入深度编辑器。
