# 状态、连接与默认操作补充

当前行为以[收敛方案](../../../果铃2.0收敛方案.md)与执行包为准。6 张概念图保留视觉参考，本文件定义其遗漏状态，界面实现前补对应视觉。

| 状态 | 可见事实与用户动作 |
|---|---|
| 空空间/无文件 | 可新建/打开和开始会话，不要求 CLI、OAuth 或课例注册 |
| API 未配置/认证失效 | 配置 endpoint、Key、模型或重新登录；保留输入与文档 |
| Token Plan 额度/限流 | 实际来源、可知的重置时间与重试；未知额度直说，不自动改按量收费 |
| 模型角色缺项 | 标明视觉/生图/编辑缺项，可选择已授权连接，不只显示“可用” |
| 加载/附件处理 | 原件、表示、范围与真实进度，超限/失败明确 |
| 正文生成/停止 | 原位草稿，当前组停止撤回；之前已提交操作保留 |
| 图片生成/编辑 | 运行/失败/取消/已生成未应用/已插入分开；参考原图可保留 |
| 构建检查失败 | 精确失败和已有成果，同任务可修复；不导入半成品 |
| 文档冲突/外部修改 | 保留用户稿、明确来源，重载或处理保存冲突 |
| 保存失败/恢复 | applied 与 saved 分开，恢复已确认内容，不自动续费运行 |
| 部分完成 | 已完成、失败和剩余工作清楚，不全绿也不丢已有结果 |
| 外部 MCP 接手 | 交接事实与授权范围；只显示收到的工具，不冒充外部完整聊天 |
| 无权限/已撤权 | 错误说明范围，旧请求不能继续修改 |
| 不支持真实流 | 明示操作级更新，不能事后播放打字动画冒充实时 |

用户要求先审阅时，同一草稿等待接受；默认直接编辑不多一个“应用候选”入口。AI 工作区、模板与知识库按需进入，一级对象是空间、文件、会话。
