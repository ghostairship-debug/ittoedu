# 02 信息架构

> 2026-09-22：以[收敛方案 v2.0](../../../果铃2.0收敛方案.md)为当前合同；API/套餐为主、OAuth 可选、统一自建执行器和外部 MCP。图稿是视觉参考，不代表旧导航/预览审批为必经流程。
## 顶层模型

### 一级结构
- 空间
- 文件
- 会话

AI 工作区/任务详情、知识库、工具和模板是按需进入的二级能力，不并列占据一级导航。

### 用户理解方式
- **文件**：工作的对象
- **会话**：持续讨论与任务线程
- **AI 工作区**：按需进入的二级能力，用于查看任务、设置模型角色、管理成果与附件
- **知识库 / 工具集 / 模板中心**：按需进入的二级能力，不抢主路径

## 产品壳层

### 左侧
- 文件
- 会话
- 我的空间 / 文件夹 / 标签

### 中间
- 主内容区
- 打开的文档、页面、画布、欢迎页或 AI 工作区

### 右侧
- AI 助手
- 上下文、过程、结果、输入框、附件、快捷动作

## 内容模型

### 文档类
- Markdown 文档
- 课件文档（含 slide / spatial / flow 等表面）
- 图片、PDF、PPT、表格等成果文件
- 其他资料文件

### 会话类
- 独立对话线程
- 支持关联多个文件
- 支持上下文芯片
- 支持沉淀为知识

## AI 的目标层级

从高到低：
1. 显式编辑目标；附件/普通选区作为已知上下文，不自动等同写入授权
2. 当前文件
3. 当前会话内已引用文件
4. 当前空间中的其他可授权内容

## 核心原则

- 文件和会话是正交关系
- 编辑对象与当前界面焦点解耦
- 普通编辑优先直达内容
- 工程级构建、可执行内容进入受控 staging 与检查；仍由同一自建执行器推进，任务长短不触发额外预览审批
