# 04 关键交互流程

> 2026-09-22：以[收敛方案 v2.0](../../../果铃2.0收敛方案.md)为当前合同；API/套餐为主、OAuth 可选、统一自建执行器和外部 MCP。图稿是视觉参考，不代表旧导航/预览审批为必经流程。
## 流程一：从会话开始创作
1. 用户打开会话
2. 输入需求，附加图片 / 文件
3. AI 读取附件并生成方案
4. 在主内容区创建或打开对应内容
5. 内容直接进入可继续编辑状态

## 流程二：从文件开始修改
1. 用户在文件树中打开文件
2. 在正文、页面或画布中框选目标
3. 右侧 AI 自动获得上下文
4. 用户提出修改要求
5. AI 直接修改当前内容
6. 用户继续手改或继续提要求

## 流程三：Markdown 正文即时编辑
1. 用户在“正文”中选择一段内容
2. 输入“请润色这段话”
3. AI 开始在正文原位生成新文本
4. 结果直接替换或以轻量修订块展示
5. 用户可撤销、继续改写、扩写下一段

## 流程四：页面 / 画布选区共编
1. 用户选中画布对象或一个区域
2. 右侧展示当前页面 / 当前选区
3. AI 基于局部上下文执行修改
4. 画布尽快反映结果
5. 过程记录沉淀在会话中

## 流程五：附件与多模态
1. 用户点击、粘贴或拖拽图片 / 文件
2. 附件预览出现在输入框上方
3. 发送后，AI 基于附件进行分析或创作
4. 结果可能产生新的文件、图像或画布修改
5. 成果沉淀至文件系统与会话记录中

## 流程六：任务与成果管理
1. 用户发起复杂任务
2. AI 展示任务规划与执行步骤
3. 中间过程、工具调用、生成成果可见
4. 产物可下载、打开、继续编辑
5. 会话与文件持续联动沉淀
